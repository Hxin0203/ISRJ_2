# 07 · Hankel 与结构分解

来源为模型思路·低秩与可辨识性；追加规划 P1/P2。

| 评审问题 | 当前判定 |
|---|---|
| 问题与数据 | 五批结构诊断以 160 个父场景为单位；有固定候选数值检验。 |
| 已有数学依据及前提 | 无噪单指数序列的 Hankel 矩阵可分为外积；子空间有交集时完美保留和消除相互矛盾。 |
| 近邻与新颖性风险 | 变量投影、低秩与子空间方法有既有数学基础。 概念本身无法作为首创证据。 |
| 未解决问题与候选贡献 | 理想秩、项目噪声分布与全局唯一恢复是不同主张。 可评价的贡献限于有明确输入条件、且有独立证据的具体主张。 |
| 资源、权限和进入条件 | 本卡允许用已有报告、原文与抽象算例作 CPU 审查。正式模型实验未排期，GPU 预算为零；需另有合规范围、资源和独立评价证据。 |
