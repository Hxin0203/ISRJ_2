# ISRJ_2 性能诊断：RSDR-Net 损失与场景设计核验

日期：2026-11-17
范围：针对任务书中 RSDR-Net 损失函数、跨脉冲约束及 Main/Extreme 场景设计进行源码和记录核验。本文不把候选试验等同于已验证有效方法，也不替代任务书要求的完整系统审计、性能失败分类或新实验。

## 结论先行

1. RSDR-Net 的常规 `rgssr_losses` 含六个损失分项：reliability、reconstruction、trusted-preservation、corrupted-reconstruction、boundary 和 H0 action。该实现中没有显式距离-多普勒图损失，也没有直接约束相邻脉冲相位/幅度连续性的跨脉冲损失。
2. RSDR 后续 D1-Pair 候选损失确实存在。其四状态公式约束的是干扰有/无两种条件下的目标增量相等。虽然实现以两个脉冲一组计算，但数学项没有相邻脉冲差分、慢时间相位或多普勒谱项，因此不宜简称为“跨脉冲损失”。
3. D1-Pair 只完成代码/工程诊断，没有进入正式模型训练。阶段记录为 GPU 正式训练完成 seed 0/3、final4 模型 0/9。因此目前没有实验证据证明 Pair 会改善 RSDR-Net，更没有证据证明把它移植到 ISRJ_2 会有效。
4. Main/Extreme 分层是 RSDR 与 ISRJ_2 均可借鉴的实验设计。它的主要价值是把常规条件与低 SNR/更宽 JSR 范围的困难条件分开报告，避免总体均值掩盖尾部退化。ISRJ_2 已按两组参数范围生成训练 parent，但训练批次打乱混合，尚未分别报告 Main 与 Extreme 的训练/DEV损失或模型性能。

## 逐项核验

### A. RSDR-Net 常规损失

源码 `G:/Project Code/ISRJ/RGSSR_ISRJ/losses.py` 中定义：

\[
L=\lambda_rL_r+\lambda_{rec}L_{rec}+\lambda_kL_k+\lambda_cL_c+\lambda_bL_b+\lambda_0L_0,
\]

默认权重依次为 `1, 1, 0.2, 1, 0.05, 0.10`。

- `reliability`：用局部能量比构造标签 \(R^*=1-E_J/(E_J+E_C+\epsilon)\)，以 Smooth-L1 监督局部可靠度。
- `reconstruction`：预测恢复信号与去斜后的期望信号之间的归一化复数误差。
- `trusted_preservation`：按可靠度加权，使可信区的输出保持接近观测值。
- `corrupted_reconstruction`：按 \(1-R^*\) 加权，重点重建受污染位置。
- `boundary`：用可靠度越过阈值的位置构造边界标签，采用二元交叉熵监督边界概率。
- `h0_action`：无目标状态下约束校正动作尽量接近零，抑制对纯噪声/无目标输入的误操作。

这些项构成“哪里可信、哪里受污染、哪里应当修改”的结构化先验。它们的定义不依赖显式跨脉冲特征。实际训练中的梯度占比和各项消融效应须由对应运行证据确定，不能仅凭默认权重判断哪项主导优化。

### B. D1-Pair 候选项是什么

候选实现位于 `G:/Project Code/ISRJ/sync_records/2026-10-30_d1f1_parallel_r4/runtime_r3/fidelity.py`。令 \(t_{1,j,1}\) 和 \(t_{0,j,1}\) 分别表示有目标、干扰存在/不存在配对状态的输出目标相关量；下标 0 表示无干扰基准，1 表示有干扰。实现项为：

\[
L_{pair}=\mathbb{E}\left[\left((t_{1,j,1}-t_{0,j,1})-(t_{1,j,0}-t_{0,j,0})\right)^2\right].
\]

它匹配“有干扰时的目标增量”与“无干扰时的目标增量”，意图约束干扰条件对目标响应增量的额外影响。实现还要求四个张量形状一致且有限；四状态共享干扰/噪声身份由单独恒等式检查。

`train_pair.py` 按脉冲切片执行前向，因此代码利用多脉冲场景中的成对状态。但损失的差分方向是四状态差，不是脉冲索引差。公式没有显式比较 \(p\) 与 \(p+1\) 的相位、复增益、残差或慢时间傅里叶系数。严格表述应为“多脉冲场景上的四状态目标增量配对一致性候选”，而不是“跨脉冲多普勒一致性损失”。

运行身份 `RSDR_D1_F1_PARALLEL_20261030_R3` 的阶段报告记载：GPU 1 正式训练未准入，完成 seed 0/3、final4 模型 0/9；R1/R2/R3 分别遇到 CPU 资源门、终态计数接口错误及资源准入问题。数值 exact 与定向 CPU 测试属于工程正确性证据，不属于模型效果证据。因此 Pair 仍是未验证候选。

### C. ISRJ_2 当前损失与跨脉冲上下文

源码 `paper2/network.py` 的 B4 总目标为：

\[
L=L_{endpoint}+0.1L_{pc}+L_{damage}.
\]

其中 `endpoint` 监督四状态校正量，`pc` 对校正误差与期望信号的匹配滤波结果计算归一化能量误差，`damage` 约束干扰存在时两个目标状态的校正差接近目标分量。它与 Pair 目标有关，但不等价：当前 `damage` 直接锚定干扰存在条件下的目标增量；Pair 比较该目标增量与无干扰条件下的目标增量是否一致。后者或许增加跨干扰条件的保护约束，但也可能与 endpoint 的监督部分重叠，其净收益与损伤风险需要梯度及受控实验确认。训练入口 `paper2/train_1103.py` 把 parent × pulse 展平，并对每个脉冲的四状态逐条送入单脉冲网络。8 脉冲共同来自一个物理 parent，但当前网络前向没有跨脉冲上下文，损失中也没有相邻脉冲相位/残差一致性项。

因此，任务书所列“当前单脉冲建模是否限制 8 脉冲多普勒处理”目前是待诊断假设。只有在同一 parent 下观察到跨脉冲残差的相干积累、相位漂移、幅度不稳定或距离-多普勒虚假峰关联后，才有依据安排小型跨脉冲约束试验。

### D. Main/Extreme 场景是否已实现

ISRJ_2 的 `paper2/data_1103.py` 对训练 512 个 parent 按索引分层：前 256 个为 Main，SNR 范围 \([-20,15]\) dB、JSR 范围 \([-12,35]\) dB；后 256 个为 Extreme，SNR 范围 \([-30,-20.0001]\) dB、JSR 范围 \([-12,45]\) dB。其余训练生成参数大体沿用同一配置，parent 还包含 8 脉冲与 3 种干扰变体。

`paper2/train_1103.py` 的 batch 抽样对全部 parent/干扰类型整体随机打乱，没有保留 profile 字段来分别汇总 Main 和 Extreme 的 batch loss。现有 DEV 角色生成也使用广范围，而不是配置为两个独立 profile 的对照角色。故当前状态应标注为：**训练数据有 Main/Extreme 参数分层；训练优化和评估尚未按 profile 分层呈现**。

RSDR 冻结配置 `G:/Project Code/ISRJ/RGSSR_ISRJ/configs/post_m51_equal_pfa_roles_v1.json` 将 Main 定义为 SNR \([-20,15]\) dB、JSR \([-12,35]\) dB；Extreme 为 SNR \([-30,-20.0001]\) dB、JSR \([-12,45]\) dB。配置分别建立 Main/Extreme 的 calibration 与 test roles，各 10,000 scenes，并且角色、用途、场景 ID 起点和生成种子分开锁定。这支持“按 profile 独立校准/测试并报告”的设计做法。该配置属于 RSDR 的后续评估方案，不能据此宣称 RSDR 所有历史训练均采用完全相同的训练分层。

## 对 ISRJ_2 可借鉴的做法

1. **保留物理 parent 分组。** 统计独立单位应是 parent；8 脉冲、3 种干扰类型和四状态是 parent 内相关观测，不能当成独立样本扩大置信度。
2. **Main/Extreme 分开报告。** 复用同一冻结检查点分别计算两个 profile 的 NMSE、目标增量失真、SJRIF、Pd 与实测帧 Pfa；同时报告总体结果。对检测指标，Main/Extreme 应使用用途分离的校准与确认 parent，不能依据确认集调门限。
3. **先诊断，再试 Pair 类损失。** 对固定模型做同 parent 跨脉冲复残差分析：脉间相位增量、残差复相关、慢时间谱能量、目标峰/最强虚假峰随脉冲数变化。若错误确实以相干方式积累，再定义明确作用于复数慢时间维的损失，并与“仅四状态配对损失”分开命名、分开消融。
4. **若借鉴四状态配对目标，明确它保护什么。** 先做无需重训的离线数值诊断，确认当前 `damage` 项是否已在约束类似的目标增量。若新 Pair 与 `damage` 数学上重叠，应比较梯度余弦、范数和覆盖状态后再决定是否设计独立消融，避免重复监督。
5. **借鉴损失可解释性而非照搬权重。** RSDR 的可靠度监督、可信区保持、污染区恢复、边界和 H0 action 有不同物理作用；ISRJ_2 当前任务定义、输入输出与恢复目标不同，不能直接复制这些损失或其权重。可迁移的是先说明每项针对的失效机制，再量化单项/交互的梯度与指标效应。

## 建议的后续判别步骤

遵循任务书 P0 优先：冻结现有模型和数据身份，不训练新权重。先按 Main/Extreme 与干扰类型分层，对相同 parent 计算逐脉冲校正残差和目标增量；然后测相干积累前后的脉压/RD 峰值、相邻脉冲复相关及相位残差。将结果与 KEEP、理想扣除诊断上界并列。若跨脉冲相干误差不显著，暂不做新增时序损失；若有稳定证据，再预注册最多三个轻量候选，并在服务器 B、专用目录和预算内以相同 parent、seed、更新数比较。
