# 09 · 轻量部署与重复测量

来源为创新性研究 §9；模型思路·轻量化。

| 评审问题 | 当前判定 |
|---|---|
| 问题与数据 | 两进程八轮前向实测，七轮 U-Net 中位延迟较低，一轮相反。 |
| 已有数学依据及前提 | 相同参数量不确定执行时间；分位数必须指定计时边界、设备与重复单位。 |
| 近邻与新颖性风险 | MobileOne 以实际设备延迟研究效率。 概念本身无法作为首创证据。 |
| 未解决问题与候选贡献 | 整链延迟、峰值内存与跨设备结论缺证；旧脚本身份仍有限制。 可评价的贡献限于有明确输入条件、且有独立证据的具体主张。 |
| 资源、权限和进入条件 | 本卡允许用已有报告、原文与抽象算例作 CPU 审查。正式模型实验未排期，GPU 预算为零；需另有合规范围、资源和独立评价证据。 |
