# ReCoVP-Hybrid 图拉普拉斯扩展筛查报告

**日期** 2026-11-27

**结论** 当前相干图拉普拉斯扩展不建议纳入主模型，也不满足进入多种子训练消融的预注册条件。

## 研究问题

本次筛查检验在冻结的 ReCoVP-Hybrid Stage 1 变量投影求解中增加图拉普拉斯惩罚，能否改善干扰恢复，同时保持目标响应和检测能力。Stage 2 沿用原检查点，不作修改。实验在本机 NVIDIA GeForce RTX 4060 上运行，没有进行训练。

图边权取归一化字典原子内积幅值的平方。每个节点先连接权重最高的两个邻居，再以逐元素最大值对称化。由此构造加权图拉普拉斯，并按物理原子范数缩放为正则矩阵。强度按其迹与数据项精度矩阵迹之比归一化。弱、强图正则对应的比值分别为 0.1 和 1.0。

比较了五种设置。基线不增加惩罚，图弱和图强使用上述图结构，置换图保留边权但打乱节点对应关系，对角控制保留惩罚对角项并移除节点耦合。

## 数据与分析方法

检查点固定为 seed 17、epoch 256。每个注册工况包含 128 个物理 parent，覆盖 SNR −30 dB 与 −20 dB、JSR 10 dB 与 30 dB 的四种组合。直达、重复和循环干扰作为同一 parent 内的重复测量，先在 parent 内聚合。独立校准集包含 1024 个物理 parent，每个变体分别校准 1%、5% 和 10% 的等虚警阈值。

主要指标为四个 SNR×JSR 工况等权平均的 U-NMSE。配对 bootstrap 按物理 parent ID 联合重采样 10,000 次。预注册要求候选相对基线至少降低 5% 的 U-NMSE，且 95% 置信区间排除零，同时限制目标损伤、1% 等虚警检测率和等虚警点虚警率的退化。强图正则还需在 U-NMSE 上优于置换图和对角控制组。通过筛查只代表可以进入后续多种子训练消融。

表中宏平均对四个注册工况等权。目标损伤按冻结评估实现计算，即目标响应误差能量除以目标能量。幅度保持率为目标复增益模值。1% 检测率使用各变体独立校准的等虚警阈值。

## 图结构特异性与预注册判定

强图正则在 U-NMSE 上优于两个控制组。相对置换图强的差值为 −0.007472，95% 区间为 [−0.009295, −0.005715]。相对对角强的差值为 −0.014815，区间为 [−0.017822, −0.012051]。这支持当前数据范围内存在图连接结构特异性。

整体性能门槛仍未通过。图强正则没有降低 U-NMSE，目标损伤和检测率均显著退化。图弱也未通过，宏平均 U-NMSE 从 0.029229 增至 0.104296，1% 等虚警检测率从 0.280599 降至 0.071615。根据预注册规则，本轮结果不支持进入多种子训练消融，也不支持把该扩展纳入当前主模型。

## 与原始关系共享设想的范围对应

本轮代码根据字典原子相干性建立 top-2 无向图，并对图连接施加拉普拉斯惩罚。原始思路中的同源重放片段分组、关系置信度和共享复系数没有进入本轮实现。两者的约束对象和物理含义不同。

因此，本轮结论针对当前相干图正则化实现。原始物理共享关系方案仍属未验证设想，本轮结果不能替代对该方案的独立筛查，也不构成它有效或无效的证据。论文当前版本不应把图扩展表述成已实现贡献。现有结果可用于记录这项正则化筛查失败，以及图结构相对控制组的特异性观察。
