# ISRJ 恢复中的可辨识性与教师证据

## RSDR-Net 的长处有多大

主网格上，两种冻结模型用相同的 256 个独立 parent 和相同的评价链。CorrectionNet 与 RSDR-Net 的受扰无目标帧虚警率分别为 20.4241% 和 7.0754%，目标增量失真分别为 0.047309 和 0.071769。较低的虚警与较高的增量失真同时出现在旧模型上。[论文表 6](../manuscript/ISRJ_2_论文修订稿_20261116.md)

令 A、B 表示在同一评价帧上两个模型分别报虚警，且沿用主网格的汇总权重。由于 P(A 且非 B) − P(B 且非 A) = P(A) − P(B)，前一种事件约占全部受扰无目标帧的 13.35% 至 20.42%，反向事件约占 0 至 7.08%。这是由边际率决定的范围。精确的分歧率须取自同帧配对事件，区间也没有计入采样不确定性。帧级判决的互补性不能直接换算成学生收益或可迁移的波形比例。

## 蒸馏能改变什么

在平方误差下，设 X 为学生部署时的观测，U 为恢复参考，T 为教师输出，均有有限二阶矩。只依赖 X 的学生拟合教师时，理想的总体最优预测是 E[T|X]；拟合参考时则是 E[U|X]。两者的偏差为 E[T−U|X]。如果教师只用 X 且已冻结，它的输出理论上由 X 决定，小模型能否以其容量和训练预算逼近该映射仍须实证。如果教师另有训练时才可见的信息 Z，理想教师 T=E[U|X,Z] 满足 E[T|X]=E[U|X]。此时教师可能降低有限数据下的监督噪声；它也无法替部署时只见 X 的学生找回每个样本独有的隐藏信息。这是平方误差的总体结论，不能由此推出帧虚警或目标损伤的改善。

Lopez-Paz 等已将蒸馏与特权信息联系起来。Menon 等在分类中说明，教师概率估计的偏差和方差会影响蒸馏价值。这里的回归论证来自条件期望。项目里值得保留的假设，是在相同学生输入、推理成本和可比训练预算下，学生是否能从旧模型获益并保有自身较低的增量失真。应分别交代教师看到的信息、学生训练时得到的监督和部署时可见的信息。采用旧模型或引入额外训练信息本身已有先例。[广义蒸馏，ICLR 2016](https://leon.bottou.org/publications/pdf/iclr-2016.pdf) · [蒸馏的统计解释，ICML 2021](https://proceedings.mlr.press/v139/menon21a.html) · [最小均方估计与正交性](https://ocw.mit.edu/courses/6-011-introduction-to-communication-control-and-signal-processing-spring-2010/f3ed10bd2a49c9ec2baf3dddb5242862_MIT6_011S10_chap08.pdf)

## 单次观测能否唯一决定恢复参考

按本文定义，观测 Y=S+J+E，希望保留的是同噪声参考 U=S+E。先固定 E。假设模型允许两组不同成分产生完全相同的 Y，却给出不同参考 U₁、U₂。只见 Y 的确定性估计器在两种情形下必然输出同一个值。由三角不等式，它在其中至少一个情形下的误差范数不小于 ‖U₁−U₂‖/2。这给出了反例必须具备什么条件；现有汇总尚未证明这类冲突在本项目的物理约束下存在，更未测出其发生比例。相似观测也需要单独讨论噪声和测量精度，不能按完全相同的观测处理。

结构分解文献提供了一个警示。只有一个非零元素的矩阵既稀疏又秩一，单凭两个结构名称无法判定它属于哪一项。Chandrasekaran 等给出的恢复保证依赖额外的不相干条件。对 ISRJ，若提出结构可分性主张，应列清假设、指出允许的反例，以及主张覆盖的范围。当前两个网络共同犯错只说明这两个模型失效，无法建立所有估计器的误差下界。[Rank-Sparsity Incoherence，SIAM Journal on Optimization](https://arxiv.org/abs/0906.2220)

## 两种已有现象有不同的解释

固定变换若在保留完整观测和已知参数时可逆，那么任一基于原观测的估计都能通过逆变换在新表示中实现。不受容量限制的最佳风险相同，小卷积网络在两种表示下的近似与学习难度则可能不同。旧 DEV 上仅切换固定去斜就产生性能差异，支持继续区分表示与模型的作用。该现象本身不能证明信息丢失或相位机制。原骨干与 U-Net 在相同尾部损失下仍有约 3.91 个百分点的帧虚警差距；这组对照改变了整套骨干，无法识别去斜的单独效应。[去斜消融](../evidence/outputs/RESIDUAL_FAILURE_DIAGNOSTIC_REPORT_20261117.md) · [四组 DEV 汇总](../evidence/outputs/correction_mf_tail_20261117_v1/FOUR_CELL_DEV_SUMMARY.json)

旧模型和小模型的整体恢复误差排名还依赖评测条件。主网格 NMSE 由 CorrectionNet 占优，稠密网格则由 RSDR-Net 占优；增量失真在两个网格上均由 CorrectionNet 占优。论文宜分别陈述跨网格重复出现的结论和依赖条件权重的结论。多个模型在单一评价分布上表现相似，也可能在其他分布上表现不同。[项目统一比较](../manuscript/ISRJ_2_论文修订稿_20261116.md) · [D’Amour 等，JMLR 2022](https://jmlr.org/papers/v23/20-1335.html)

## 判断顺序

1. 已有的去斜交叉对照优先用于厘清学生基线。不同轮次的结果应保留各自的数据和训练身份。
2. 教师方向优先回答两个彼此独立的问题：旧模型在哪个评价量上确有长处，以及相同预算下学生能否获得有实际意义的收益。保留同一学生直接监督的对照、逐种子配对结果、实际工作点与目标增量失真。结果只在改变工作点时出现，应收窄对知识迁移的解释。
3. 若研究可辨识性，先给出满足项目假设的反例或唯一性论证，再讨论其代表性。若没有此类证据，保留“当前模型未分开”的表述。
4. 通过上述检验后，仍须与最近邻工作进行完整比较，并用独立数据确认。本文是对既有汇总和原始文献的分析，没有新增训练结果。
