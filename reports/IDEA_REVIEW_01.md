# 01 · 物理变换与坐标一致性

来源为两份资料的方向一、相位与去斜章节。

| 评审问题 | 当前判定 |
|---|---|
| 问题与数据 | 小样本变换诊断涉及 16 个场景；去斜历史对照微批不同。 |
| 已有数学依据及前提 | 在可逆固定变换下可换回原坐标；可逆性不能推出一般非线性网络等变。 |
| 近邻与新颖性风险 | 群等变网络已有 Cohen 与 Welling 的系统构造。 概念本身无法作为首创证据。 |
| 未解决问题与候选贡献 | 域内严格等变与表现差距的因果关系均缺证。 可评价的贡献限于有明确输入条件、且有独立证据的具体主张。 |
| 资源、权限和进入条件 | 本卡允许用已有报告、原文与抽象算例作 CPU 审查。正式模型实验未排期，GPU 预算为零；需另有合规范围、资源和独立评价证据。 |
