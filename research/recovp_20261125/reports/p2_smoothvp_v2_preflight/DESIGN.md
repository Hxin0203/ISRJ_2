# SmoothVP-Net v2 CPU preflight

本轮仅使用初版检查点绑定的同一批 16 个 TRAIN parent。正式 GPU 训练的暂停标记继续生效。P0 原进程及其收尾监控独立运行。

## 准入依据

S4 使用包含频偏的等效 LFM 延迟，K=8 的 Oracle-β 全局残差为 1.298%，repeat 为 3.557%，cyclic 为 0.321%。S2 和 S3 的受控替换均降低残差，允许开展 CPU v2 预检。

单脉冲真实延迟数最多为 10，采用任务书优先方案 (i)，提取八个独立峰，每峰一个共享的有界 ±2 点连续微调。超出八个延迟的能量损失保留在 S4 审计中。Oracle 替换的真实支撑信息仅用于阶段 1。

## 架构

- 共享编码器与解码器复用初版结构，共 50,634 个实参数。
- 从完整非负匹配滤波延迟区间提取局部峰，最小峰距为 6 个采样点。候选区间为 2–1797，加入微调后覆盖 0–1799。该范围支持部分落入接收窗的重放。初版 0–1200 范围限制另有 Oracle 对照。
- 连续精调头逐候选共享权重，由局部共享特征、全局共享特征、候选位置和峰幅值预测。
- 已知 LFM 模板用 4096 点零填充 FFT 和线性相位生成。每路计算观测与模板的相干乘积，使用 5/11 点复滑动平均的实部、虚部、幅值作为支撑特征。
- 共享软窗头输出实数 sigmoid 窗，使用 3 点平滑。S4 中 9 点平滑相对真值硬窗增加约 6.1 个百分点的 Oracle 残差，因此减少固定输出平滑宽度。相干特征的 5/11 点窗口沿用任务书方案。
- 精度头逐候选共享，保留初版的正精度形式、1e-4 下界、22 的初始偏置和连续指数稳定化。旧精度头与真值字典组合仍有显著残差，因此共享头在本轮重新训练。
- 总有效实参数为 58,853，预算仍为 56,728–62,700。字典、精度与线性求解在 complex128 中计算，校正波形写回 float32。

## 边界与置换

峰提取是固定、无参数的离散候选步骤，微调、软窗、精度及求解保持可微。对同一候选集合的顺序置换，共享头保证等变，闭式合成应保持不变。候选集合成员发生变化仍可能造成漂移，需用配对观测直接审计。

短窗相干平均对匹配切片提供低频提示。相近延迟的差频可能保留较大幅度，因此不预设其必然消除目标或其他重放成分。

## 固定优化与评测

两个坐标各用 seed 17。沿用初版的 768 次 Adam 更新（lr=1e-3），然后重建 Adam 进行 3,072 次更新（lr=3e-4）。数据顺序 RNG 分别为 20261125 和 20261126，micro-batch 为一个八脉冲四状态记录，梯度裁剪为 5。损失保持 endpoint + 0.1 pc + damage + 0.05 tail，无新增正则项。

仅评估固定第 3,840 次更新，保留第 768 次与第 3,840 次权重及全部训练轨迹。数值、梯度和初始无扰检查同样限于这 16 个 TRAIN parent。

置换单测在初始与训练后执行，最大校正波形差须低于 1e-5。时延变化同时报告按固定通道配对及最小代价匹配后的变化，避免把列顺序交换直接解释为定位漂移。

## 审阅闸门

G-v2-1、G-v2-2 和 G-v2-3 使用任务书给出的残差、漂移、泄漏和无扰阈值。类型改善与虚警改善附同 parent 配对 bootstrap 95% 区间。虚警≤10%作为任务书给定目标单列记录。G-v2-4 需要六格完成、坐标锁定及最终检查点 SHA-256 核验。

无论本轮闸门结果如何，结束后均保持正式 P2 GPU 训练暂停并等待人工审阅。
