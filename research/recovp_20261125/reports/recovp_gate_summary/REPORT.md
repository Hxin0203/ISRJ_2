# Gate-ReCoVP

SNR/JSR 优先使用规范 snr_db/jsr_db；生成器定义为有效目标支撑平均功率/噪声方差、有效干扰支撑平均功率/有效目标支撑平均功率的 10log10。帧值先对有效脉冲线性比取均值再转 dB；SNR 使用全部八脉冲，JSR 仅使用受扰脉冲。整段能量比因占空比不同不替代该口径。

路由 **NO_GO_EXP1_PREFLIGHT**。本轮没有新神经模型的 DEV 成绩，不以 TRAIN16 替代 DEV。
正式 GPU、NoEquiv、SoftShare、CVaR 与完整神经模型延迟均未启动。独立确认始终锁定。

## 最终审阅：性能门槛未通过

本轮 Exp0/Exp1/Exp2a 已完成；正式训练的条件尚未满足。下面的性能数值均来自固定 TRAIN16、seed 17、第 3840 步，不能据此宣称已超过 256-DEV 基线。

该 TRAIN16 的全局 Pd 为 66.667%，目标增量损伤为 0.049336。低虚警并不足以单独证明恢复性能，检测率与损伤也完整保留在分层收据中。

## 数学、选型与共享机制收据

- 有效实参数 Base 为 58,943，SoftShare 实现为 60,798。全部采用实卷积；内部特征与网络计算使用 float64，闭式求解使用 complex128，部署写回 float32，后续计时必须计入这些成本。
- 末步受测样本的 complex128 最大复缩放相对误差 5.028e-13、最大列置换相对误差 2.198e-13，均满足 1e-11 门槛；float32 检查通过。退出节点的行列 L2 范数和活跃块差异检查通过 1e-12 门槛。
- 峰值归一严格使用既定 max(peak, 0.05) 公式；末步数学检查的受测原子有 73.438% 触发保护分母。此时窗口峰值小于 1，不能声称所有原子的尺度歧义均已完全消除；本轮没有事后修改阈值。
- Exp0 的 TRAIN512 零训练比较锁定 E0_rect_k12；21 个配置的复缩放锚点变化均为 0。该锁定方案全局能量加权 ±2 点召回为 60.464%，真干扰命中留存为 99.239%（仅有原始命中的 505 个 parent）。加窗/CLEAN 没有胜出，完整负结果均保留。
- Exp2a 正确物理共享方向显示降低噪声代价的潜力，但未训练节点头在强共享下出现明显拟合偏差；有限弱共享的条件证据不能证明盲相位预测已解决。原生 TRAIN512 纯噪声负对照中，复制观测相位的拟合噪声能量为固定方向的 6.513 倍；该对照不进入正向模型。
- 原生元数据与 active-power 定义交叉核验通过；全窗 SNR 与 active-support SNR 的差为 -4.771213 dB，因此所有分层继续读取原生 snr_db/jsr_db。

最终状态保持 **NO_GO_EXP1_PREFLIGHT**。Base 正式 seed 17/29/41、NoEquiv、SoftShare 训练、CVaR 四格及完整模型 GPU/CPU 延迟均标记未启动；没有正式模型 DEV 新结果，也没有读取独立确认集。源码、检查点和数据绑定核验见 [VERIFICATION.json](VERIFICATION.json)，复现入口见 [REPRODUCE.md](REPRODUCE.md)。
