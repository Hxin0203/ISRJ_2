# SNR/JSR 同口径基线

SNR/JSR 优先使用规范 snr_db/jsr_db；生成器定义为有效目标支撑平均功率/噪声方差、有效干扰支撑平均功率/有效目标支撑平均功率的 10log10。帧值先对有效脉冲线性比取均值再转 dB；SNR 使用全部八脉冲，JSR 仅使用受扰脉冲。整段能量比因占空比不同不替代该口径。

不重训、不重新选 epoch，复用已核验的 256 DEV parent 固定末轮指标。
