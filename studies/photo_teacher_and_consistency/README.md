# 宽教师的优势能否传给小 U-Net

**宽教师在两组开发照片上比等时间小 U-Net 高 0.184、0.163 dB。** 把原图和镜像的教师预测对齐后取均值，教师在 256 个新账号上又提高 0.041 dB。学生学这个平均预测，相对普通蒸馏仅差 −0.001 dB。同样的学生训练时间给直接监督反而高 0.092 dB。该蒸馏方案按事前规则停止。无教师的细节监督在 240 步的小预算下有重复收益，在完整预算下未达预设效应量。

本研究在公开花卉照片上检验教师蒸馏和一个无教师的数学方案。任务是把每个像素记录为四个原像素平均值的灰度照片放大两倍，恢复原图中的纹理。上轮是手写数字去噪，这次同时换了图像来源和退化方式。本文的指标描述这个摄影任务，CorrectionNet 原应用的证据仍见上轮报告。[上轮结果](../image_distillation_pilot/README.md) · [跨领域方案与数学推导](research_notes.md)

## 数据、时间和判据

TensorFlow Flowers 的来源档案含 3,670 个文件、3,669 个不同 Flickr 照片 ID 和 1,534 个摄影账号。根据原包署名分组，每个账号按固定哈希选一张。600 个账号用于训练，开发 A、B 各 128 个，C 预留 256 个，另有 422 个账号未用。不同划分没有共享的账号标识或照片 ID。署名不能识别同一自然人的不同账号，也不能排除不同摄影者拍到相似场景。图像转灰度并统一到 64×64；训练随机取 32×32 裁块，评价用全图。原图为照片，低分辨率观测由程序生成。原图与逐张署名保留在发布者提供的 CC BY 2.0 数据包中。[数据集说明](https://www.tensorflow.org/tutorials/images/classification)

普通小 U-Net 有 3,061 个参数，宽教师有 21,121 个参数。六个训练种子为 17、29、41、53、67、79。在一台机器上使用单个 PyTorch CPU 线程，预热后每次给宽、窄模型 14 秒，包含采样、前向、反向和更新。宽模型实际完成 947–959 次更新，小模型完成 2,147–2,202 次。两种模型使用相同的训练照片和裁块序列前缀。比较两个架构各自训练所需的时间，与比较完整蒸馏流程的时间分开计算。

阶段三先冻结摄影账号、训练种子、比较方式和判据。每个开发子集要求平均 PSNR 增益至少为 0.10 dB、六个训练种子全部为正，且一阶梯度 MAE 相对增幅不超过 1%。教师还要在每个种子优于短训学生，并且逐照片的 PSNR 收益与边缘误差降低之间的 Spearman 相关至少为 0.25。0.10 dB 和 1% 均为本试验的实用界值。区间按照片配对重采样，给定这六组已训练模型。所有比较同时提供裁剪到显示亮度范围后的 PSNR。[评分前冻结的阶段三方案](https://github.com/Hxin0203/ISRJ_2/blob/33b9b3b1e6690a88b8333c09a98c9318e71880e6/studies/photo_teacher_and_consistency/protocol.json)

## 等时间教师与无教师替代方案

网络输出均接受同一项解析校正，使每个像素块的平均值与输入相符。这样，两种网络的剩余误差都来自块内细节。

| 相对各自对照的平均 PSNR 增益 | 开发 A，dB | 开发 B，dB |
|---|---:|---:|
| 宽教师相对 240 步小 U-Net | +0.5370 | +0.4880 |
| 宽教师相对同样训练 14 秒的小 U-Net | **+0.1843** | **+0.1629** |
| 小 U-Net 改为只训练块内细节，双方 240 步 | +0.1325 | +0.1361 |
| 同一改法，双方更新数匹配到普通学生的完整预算 | +0.0870 | +0.0678 |
| 同一改法，双方训练时长均为 14 秒 | +0.0918 | +0.0781 |

宽教师相对等时间学生的照片配对 95% 区间分别为 [0.1531, 0.2175] 和 [0.1304, 0.2003] dB。梯度 MAE 降低 2.07% 和 2.02%；平均到每张照片后，93.0% 和 94.5% 的照片同时改善两项指标。逐照片收益的 Spearman 相关分别为 0.813 和 0.797。按训练照片的参考纹理强度预定三组，教师在 A 中对低纹理组的 PSNR 改善最大，在 B 中对中纹理组最大。教师总体达到资格线，根据纹理分组指定“最值得教”的那一类缺少重复证据。[逐种子结果、区间与模型哈希](results.json)

无教师方案改变了训练梯度，在短预算下确实有效。在完整预算下，两种开发集、两种预算匹配方式和全部种子的方向仍为正，但四个均值均低于事前的 0.10 dB。该方案的完整预算比较按原判据停在开发阶段。A、B 对同一骨干和六个共同训练种子的复核，也无法代替跨数据来源的确认。

如果将宽教师直接与这版等时间的细节监督学生比较，A、B 的领先量只剩 0.0925 和 0.0848 dB。这是开发后的描述性比较。它说明一个更强的普通学生就能解释原先约一半的师生差距，也解释了为何后续所有蒸馏对照都给学生相同的细节监督能力。

## 哪些提升可以直接由数学解释

- **改善均值就能提高 PSNR。** 给训练完成的小 U-Net 作一次输出校正，A、B 分别提高 0.0187、0.0213 dB，六个种子均没有一张精确观测照片的浮点 MSE 变差。给双三次插值做同样的校正，增益约为 0.329、0.336 dB。这两项都保持每个像素相对块均值的偏差。把低分辨率观测改为含标准差 0.05 的读数噪声后，小 U-Net 的同一项校正反而平均降低 0.0390、0.0368 dB；按“照片 × 训练种子”计，69.8% 和 65.8% 的比较变差。这是精确观测假设失效的压力测试。
- **测量相同，细节可以不同。** 将每个 2×2 像素块中的两列互换，256 对开发照片的整数块和全部相同，256 对参考图又全部不同。人为让每对参考等概率，在 A、B 上，任何单幅预测的平均每像素 MSE 下界分别为 0.0027825、0.0024363。这个下界属于构造的二选一问题，数值不能当作自然照片的真实误差下界。
- **有些新损失实际给出相同更新。** 当学生输出已经满足块均值约束，平方损失匹配教师整图，或只匹配教师的块内细节，两种写法仅差一个与学生无关的常数。六个真实模型对上的双精度核验中，学生参数梯度的最大绝对差为 $5.43\times10^{-20}$ 以下。给这种改写单列一个蒸馏模块没有实验依据。[公式与成立条件](research_notes.md)

解析校正和只学习零空间分量分别有直接的图像恢复与逆问题先例。这里的研究价值在于量出各自解释了多少收益，并以相同推理图比较训练方法。尚无依据认领新的骨干结构。[Bahat 与 Michaeli，CVPR 2020](https://yuvalbahat.github.io/Explorable-Super-Resolution/) · [Schwab 等，Inverse Problems](https://doi.org/10.1088/1361-6420/aaf14a)

## 教师迁移的留出结果

通过开发资格后，固定一个独立的教学假设。宽教师分别看原图和水平镜像，将第二个输出翻回来，然后让学生模仿二者的平均值。每个小学生推理时都只看一次原图。三个蒸馏组各训练 480 步，干净参考和教师参考各占一半，使用同一学生初值、同一照片和裁块顺序。按图随机挑一个方向的对照也计算两个教师输出，只改变用于监督的参考。空间变换集成在超分辨率中已有先例，这里检验的是它的收益能否转移到单次前向的学生。[EDSR 的几何集成，CVPR Workshops 2017](https://openaccess.thecvf.com/content_cvpr_2017_workshops/w12/papers/Lim_Enhanced_Deep_Residual_CVPR_2017_paper.pdf) · [打开 C 前的教学方案](https://github.com/Hxin0203/ISRJ_2/blob/1bdf4d6e32429320313394c5f715e4f90a145f1c/studies/photo_teacher_and_consistency/teaching_protocol.json)

全部六个教师与 42 个学生检查点的身份在 C 评分前登记。C 的 256 个账号各取一张，没有与训练、A 或 B 共享摄影账号标识、原始照片 ID 或完全相同的标准化图像。这些账号来自同一花卉图库。C 上每个条件都使用同一份照片，训练种子有六个。[评分前检查点登记](https://github.com/Hxin0203/ISRJ_2/blob/dbf2fd5947954633308dc49273d5c317ea31c691/studies/photo_teacher_and_consistency/fit_manifest.json)

## 研究决定

1. **保留等时间直接监督作为常规对照。** 双方向蒸馏与直接监督都做 480 次更新时，蒸馏有约 0.043 dB 收益。给两者相同训练时长，结论反向。实验回答的是小学生在这些更新数和实测预算下的表现。
2. **把只学块内细节作为短训练预算的强基线。** 240 步时有连续的正结果，完整预算上的收益更小。一致性投影与零空间学习均有近邻工作；仅凭这批结果，还不能把两者作为独立架构创新。
3. **停止同一教师的翻转平均蒸馏。** 若继续研究教师，更有区分度的问题是训练时独有的第二次真实曝光是否提供可转移的监督。届时最关键的对照是让直接监督也能用这些曝光生成参考，并给它相同计算时间。这个问题需要有同场景重复曝光的新数据；本轮单幅下采样照片没有检验它。
