# 教师蒸馏的两项手写图像恢复试验

**结论：教师比学生强，但普通输出蒸馏的平均收益只有 0.0204 dB。按开发集字符类别选择教师，在 3,823 张未见图像上也没有优于随机选择。两项试验均未达到各自的事前门槛。** 对这批数据和这些训练预算，增加普通学生的训练步数取得的收益更大。按字符类别选择只是选择性蒸馏的一种具体实现。

## CorrectionNet 现有证据更新

重新从已归档的四组记录提取三个共同训练种子在同一批 256 个 DEV 场景上的均值。CorrectionNet 相对 U-Net 的受扰帧虚警差距从 4.1233 缩到 3.9063 个百分点，缩小 0.2170 个百分点，约占原差距的 5.3%。检测率差距从 −0.6076 缩到 −0.1736 个百分点；目标增量损伤之差从 +0.01435 扩到 +0.01473。该表对应两种骨干、两种损失，无法识别固定去斜与损失的交互。本文没有新增雷达训练结果。下述图像研究只检验通用的教师假设。[已归档四组 DEV 汇总](../../evidence/outputs/correction_mf_tail_20261117_v1/FOUR_CELL_DEV_SUMMARY.json)

## 试验一：干净标签以外，教师能带来多少收益

使用 scikit-learn 自带的 1,797 张真实手写数字图。每张图视为一个 parent，按数字类别分层，1,197 张训练、300 张开发、300 张留出测试。各模型面对同一张原图和同一次测试噪声。噪声是在归一化像素上加入的高斯噪声，随后裁剪到有效亮度范围。问题是二维图像去噪；测试图不是实拍噪声观测。[数据说明](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

每个种子训练一个 21,121 参数的宽 U-Net 教师，普通学生和蒸馏学生各为 3,061 参数。普通与蒸馏学生共享初始化、训练图像顺序、逐像素噪声、优化器与 240 次更新。蒸馏一半权重给干净参考，一半给冻结教师输出，推理时只有学生。对平方误差，这与对两个参考的加权平均做回归具有相同的学生梯度。长训对照是同一个普通学生继续训练到 720 步。宽教师需要 480 步训练；“长训步数等于教师与短学生更新次数之和”不等于相同 FLOPs 或墙钟成本。[事前协议](protocol.json) · [实验代码](run.py)

| 留出 300 张，跨三种子均值 | 每图 PSNR 均值，dB ↑ | 横纵像素梯度 MAE ↓ |
|---|---:|---:|
| 含噪输入 | 14.4125 | 0.19458 |
| 宽教师 | 18.6479 | 0.10880 |
| 普通学生，240 步 | 17.4175 | 0.12636 |
| 普通输出蒸馏，240 步 | 17.4379 | 0.12697 |
| 普通学生，720 步 | 17.9464 | 0.11827 |

种子 17、29、41 的蒸馏 PSNR 收益分别为 **−0.00054、+0.02246、+0.03921 dB**。按原图配对、以三个已训练模型对为条件的 95% bootstrap 区间为 **[−0.00046, +0.03963] dB**。教师在三个种子的 DEV 上均领先，蒸馏的梯度 MAE 平均增加 0.48%，处于预设 1% 容限内；PSNR 收益未达预设 0.10 dB，也未做到每个种子方向一致。长训普通学生比短训蒸馏学生高 0.5085 dB。[完整结果及哈希](results.json)

## 试验二：先判断教师擅长教哪些字符，再选择性地学

第一项完成后，另行固定第二项问题、选择规则、对照和判据。每个种子只用原来的 300 张 DEV 图，计算教师相对普通学生在 0 至 9 各类字符上的平均 PSNR 增益，选择增益最大的五类。训练时仅这些类别接收教师监督，权重 0.5。学生推理完全不需要字符标签或教师。[第二项事前协议](selection_protocol.json) · [选择性蒸馏代码](selective_digits.py)

为区分“知道该学谁”与“教师用得少了”两种解释，加入两项严格匹配的对照：每个训练批次把相同总教师权重均匀分给所有图；或在同一个批次打乱教师掩码，保持使用教师的图数和权重。在相同三种子下，另保留完全无教师、全样本 0.5 普通蒸馏、长训普通学生和宽教师。

本轮外部评价使用 UCI 手写数字库的另 3,823 张图。数据取自 OpenML 28 v1，文件 MD5 与发布元数据一致，SHA-256 收入协议。核验了合并数据末尾 1,797 张图及其标签与首轮源数据逐项相同，前 3,823 张图与之无任何相同像素 parent。UCI 记载原始两组来自不同的书写者；此次没有逐作者标识，区间按图像计算。两批仍属于同一手写数字库，噪声仍为模拟像素噪声。[UCI 数据说明](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits) · [OpenML 数据版本](https://www.openml.org/d/28)

| 外部 3,823 张，跨三种子均值 | PSNR，dB ↑ | 梯度 MAE ↓ |
|---|---:|---:|
| 含噪输入 | 14.3692 | 0.19498 |
| 宽教师 | 18.4906 | 0.11008 |
| 普通学生，240 步 | 17.3255 | 0.12658 |
| 普通输出蒸馏，240 步 | 17.3428 | 0.12724 |
| 逐批总教师权重相同，均匀分配 | 17.3335 | 0.12750 |
| 逐批打乱选择，权重相同 | 17.3377 | 0.12724 |
| **按教师优势选择五类字符** | **17.3326** | **0.12720** |
| 普通学生，720 步 | 17.8484 | 0.11886 |

| 选择性学生减去对应对照 | PSNR 均值差，dB | 原图配对 95% 区间，给定三组训练 |
|---|---:|---:|
| 无教师 | +0.00712 | [+0.00228, +0.01211] |
| 普通输出蒸馏 | −0.01024 | [−0.01463, −0.00598] |
| 逐批同权重均匀分配 | −0.00091 | [−0.00510, +0.00320] |
| 逐批随机打乱 | −0.00517 | [−0.00964, −0.00052] |

三个种子选出的字符依次为 0/6/9/2/3、4/0/6/5/3、6/0/4/5/7，只有 0 和 6 在三次中均入选。对无教师学生，种子 17、29、41 的收益分别为 +0.03869、−0.01092、−0.00642 dB。虽然按图像计算的均值差区间为正，两个训练种子却落后，平均收益也远低于 0.10 dB。将大量测试图当成很多次独立训练会高估证据。该选择规则未通过。外部数据上的长训普通学生 PSNR 比选择性学生高约 0.516 dB；这项研究没有测量端到端训练延迟或能耗。[全部种子、对照、区间与来源哈希](selection_results.json)

## 逐步验证计划与停止条件

| 阶段 | 能回答什么 | 通过条件与本轮决定 |
|---|---|---|
| 1. 教师资格与普通蒸馏 | 在相同学生预算下，较强教师能否带来有实际意义的额外收益？ | 已实测。教师资格通过；小学生输出蒸馏未过预设收益门槛。保留它为后续普通蒸馏基线。 |
| 2. 选择是否有价值 | 按字符类别估计教师强项，能否胜过相同权重的随机选择和均匀模仿？ | 已实测。外部样本及逐种子结果均未提供稳定优势。停止此选择器，不继续用这 3,823 张图挑类别或调权重。 |
| 3. 是否有不同于“教师本身更强”的新证据 | 若继续图像恢复研究，先在新的照片开发数据上比较普通学生与等训练时间的学生，逐场景量出教师相对两者的优势是否在另一开发子集重现；检验参考误差和细节保真是否指向同一批场景。 | 先冻结优势定义、数据分组和最小有意义差异。若教师优势不重复，或普通学生延长训练即可解释差距，到此停止。只确认教师更强，还不足以进入方法定稿。 |
| 4. 检验一种新的教学假设 | 只有上一步找到可重复的现象，才在公共图像任务上冻结一个可证伪机制，同场比较无教师、普通输出蒸馏、同权重随机控制、等时间长训。 | 在未用过的场景上达到预定质量增益、保真非劣界和同设备推理成本要求，同时保留各训练种子。若普通蒸馏已经解释收益，结论收窄为压缩或训练效果。 |
| 5. 区分可迁移方法与专用骨干贡献 | 在另一公开民用恢复任务上，让同样调优的普通 U-Net 也使用通过的训练方法。补足最近邻全文比较，列明增加了哪些监督、信息和训练成本。 | 两种骨干都改善支持训练贡献；同训练同成本下专用骨干仍持续领先，才支持额外结构贡献。独立数据、实测成本或近邻证据不足时保留候选身份。 |

## 复核与运行

两个程序只运行 CPU 图像实验。首轮数据随 scikit-learn 提供；外部 ARFF 可从第二项协议中的 OpenML 地址获取。本次使用 Python 3.13、PyTorch 2.9.1、scikit-learn 1.7.2、NumPy 2.2.6；更精确的版本与 SHA 见结果文件。代码在计算过程中只保留内存内模型。发布内容为源码、协议、文献表、报告和汇总指标。

```text
python -B studies/image_distillation_pilot/run.py
python -B studies/image_distillation_pilot/selective_digits.py outputs/image_distillation_pilot/optdigits_openml28.arff
```

首个程序可在末尾指定新的结果文件路径，第二个程序可通过 `--output` 指定。本次已在同一环境以独立进程分别重跑两个程序并写入新路径，两份汇总 JSON 均与各自首次运行逐字节相同。该检查验证计算可复现；训练种子和数据还是原来的两组。
