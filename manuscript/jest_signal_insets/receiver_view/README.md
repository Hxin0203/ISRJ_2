# 完整回波与 ISRRJ 接收记录

[时域记录图](receiver_records.png) 上下两幅共用 0–30 µs 快时间轴。上图为纯净复基带 LFM 的同相分量；下图为同一脉冲的接收观测，包含目标、ISRRJ 和接收噪声。两幅图均保留全部 1800 个原始采样点，以原幅度作图，纵轴刻度独立。此例来自项目已登记的仿真库。

选用物理父样本 2026112901000017 的第 3 个脉冲（索引 2）。为满足结构图展示目的，选例时查看了登记主集前 128 个父样本中首个受扰脉冲的振荡密度。该例受扰分量在有效区内的实部过零数为 177，接近这批脉冲的上四分位数 176.25，目标和干扰的首尾均在记录内。该选例用于说明波形形态。有效区定义为干扰幅值超过其脉冲峰值的 1%，只统计相邻两个采样点均在有效区的过零。

采样率 60 MHz，脉宽 10 µs，设计带宽 30 MHz；用保存的复数相位差复核，扫频斜率为 3.00 MHz/µs。名义 SNR 为 +10 dB、JSR 为 +20 dB，采用数据集定义的功率口径。

所有图均有同名 PNG。透明底波形保留整个目标脉冲和全部受扰区段，去掉末段的背景留白，纵轴独立缩放。字典来自 seed 17、第 256 轮模型，16 个原子共享 −48 至 0 dB 色标。
