## 2. 独立问题清单

### DOM-001｜严重性：高｜阻塞：是，阻塞当前近邻定位与创新性结论

**观察及证据：**现稿 §6.1 仍写 ISRJ-FNet“摘要已提出”及上述两项“完整方法差异仍需逐式核查”。R07 p2–3 已明确：输入是多脉冲复 HRRP 矩阵；实虚通道拼接编码后，通过慢时间深度卷积、距离对称建模、通道注意力与 softshrink 生成特征软掩码；式(9)在编码特征上滤波再解码；式(10)–(11)在同一干扰下对原目标及沿距离翻转的目标训练，约束两分支掩码一致。R06 p5–9 已给出 LFM 时延字典与分块 Fourier/STFT 字典，式(26)联合两类系数的 L1 正则，式(30)、(33)–(35)明确 ADMM 展开。全文缺口已经消除。

**影响：**继续保留旧说法会让读者误以为论文刻意回避最接近的结构保真与双分量模型。FNet 先例也使“目标扰动下约束干扰相关估计”不能按全新一般思想宣传。

**验收：**引言和讨论同时补入 R06/R07 方法差异与适用对象；删除全文尚缺、仅知摘要等状态词。可以明确本次“未复现作者代码、未完成统一性能比较”，这与“缺全文”是不同问题。

### DOM-002｜严重性：高｜阻塞：是，阻塞广义复值残差/门控原创性

**观察及证据：**R03 p5 式(10)–(15)已将复值卷积残差网络作为 FISTA 的可学习近端映射，包含复值残差块与长跳连。R15 p6 式(24)、p7 式(25)明确由保留样本掩码池化得到序列级门控 α，以 `h⊙(X−α Nhat)` 控制残余噪声撤销；p8 的去噪监督为掩码内复域 MSE＋幅度损失。现稿已有对前作继承的自我限定，但引言未纳入这两篇直接机制近邻。

**影响：**“模型驱动再残差修正”“小门控趋近恒等”“复值残差恢复”均不是足够的独立贡献定义。仅比较层数或参数量不能解决同质化疑问。

**验收：**新增 R03、R15，清楚比较修正对象（干扰残差/噪声/稀疏系数）、处理顺序、输出域及监督。把贡献落在本文具体的局部窗字典、正则系数消元与后续干扰精修组合，不宣称首次模型与学习结合或首次门控保真。R03 的分实虚 CReLU 不能被视作自动满足全局相位等变；R15 的 I/Q 实值网络同理。

### DOM-003｜严重性：高｜阻塞：是，阻塞“首次重视保真”或“保真约束必然独特”

**观察及证据：**R08 p3、p9–10 已明确同时保持幅相，并把时域 MSE、脉压幅度 dB 差与归一化幅度差组成联合损失；p14 还展示距离/速度脉压。R07 p3 目标翻转而固定干扰的两分支训练，已经与本文固定背景目标干预存在概念相邻性。

**精确区别：**FNet 比较的是两个目标外观下的**掩码一致性**，不是本文有/无目标输出差与已知目标的**有限差分误差**；CVEDNet 输出干净目标并显式抑噪，本文输出同次噪声实现的无干扰观测。两者既不是相同损失，也不足以断言没有其他先例。本文四状态/含噪参考又沿用作者前期工作[29]，不能再次计算为本篇首次创新。

**验收：**明确沿用基础与新组合；写“采用/结合/在本设定下检验”，不要写“首次提出保真约束”。保留式(5)、式(7)–(10)作为监督与诊断定义，不把其代数恒等式包装成新的分离可辨识性定理。

### DOM-004｜严重性：高｜阻塞：是，阻塞把新 SNR/JSR 报告合并进同 DEV 表3或据其判优

**观察及证据：**`HYBRID_RSDR_SNR_JSR_COMPARISON_20261125.md` 开头明确 Hybrid 为 DEV256 parent 均值分桶，RSDR 为第一篇 168 个精确条件格均值的等权汇总；不是共享 parent。该报告 RSDR 总体 `u_nmse=0.1023, damage=0.0718, Pd=68.0%, Pfa=7.1%, SJRI-F=4.74 dB`。现稿表3的同 DEV RSDR 为 `0.03343, 0.09470, 86.98%, 5.08%, 11.338 dB`，来源为既有 `full_review/REPORT.md`。两组数字均有各自对象，不能互换。

**影响：**新报告总体点估计方向与表3不同主要受评测分布/权重影响，不能写成模型被“更新纠正”或性能进步；相同指标公式不等于相同试验。Hybrid 的 SNR 是 parent 内原生 SNR 均值，JSR 是跨脉冲/变体均值分桶，也不等于对单一固定物理条件的受控扫描。

**验收：**表3保留同 DEV 身份；若引入新报告则单列“跨评测分布的描述性对照”，清楚列分桶对象、权重、样本量、不配对及无统一等虚警。不得由 Hybrid 区间与 RSDR 点值的位置判断显著差异。不得把 SNR/JSR 边际曲线写成干扰类型条件曲线或机制效应。新报告中“优势主要出现在中低 SNR 与中等 JSR”的语句应弱化为“在不同聚合口径下观察到若干较低误差点估计，尚不能归因于方法优势”。

## 4. 可直接纳入正文的中文段落

### 4.1 引言：系统条件与接收端任务

针对 ISRJ 的处理首先受到系统可调整资源的限制。主动方法通过改变发射结构增加真实回波与转发片段的差异。例如，Li 等将脉内子载频捷变与混沌相位编码结合为 SSFA-MCPC 波形，并依据各子脉冲脉压峰值，用 Otsu 阈值选择滤波分量，重新构造接收失配滤波器[R02，PDF p3–6]。这一路线同时利用发射波形和接收滤波的自由度。对于发射 LFM 波形固定的接收系统，还需研究仅依赖接收观测和已知波形的干扰估计与恢复。Su 等从匹配滤波内部的累积过程区分完整回波与局部转发片段，通过波形域自适应积分及补偿构造输出[R04，PDF p3–7]。因此，接收端抑制既可以作用于波形本身，也可以作用于脉压积累过程；两类输出接口及噪声处理要求需要分开讨论。

### 4.2 引言：显式重构与复值恢复

在片段选择与重构路线中，Huang 和 Zhang 先利用 CFAR 定位并移除受扰片段，再将剩余观测写成部分 Fourier 测量模型；其 CV-FISTA-Net 以复值残差网络替代传统近端映射，并通过随机投影增广适应干扰位置和占空比变化[R03，PDF p2–6]。近期，点级时序分类与稀疏重构框架进一步将观测选择、门控残差去噪和 OMP 重构串联起来，其中 IQ-RDNet 通过掩码感知池化控制残余噪声的撤销强度[R15，PDF p4–8]。与之不同，CVEDNet 直接从受扰复波形恢复干净目标回波，并使用时域误差和脉压幅度约束共同训练[R08，PDF p5–10]。这些工作表明，复值表示、残差学习、门控及多域损失已被用于抗 ISRJ；其差异主要在于选择哪些观测、修正什么分量以及最终恢复何种参考。

### 4.3 引言：最接近的结构与保真先例

模型与数据结合的近期研究已经直接讨论目标保持。MCA-ADMM-Net 将时延 LFM 字典和局部 Fourier/STFT 字典分别用于目标与干扰，通过双分量稀疏模型和 ADMM 展开同时估计两者[R06，PDF p5–9]。面向多脉冲 HRRP 的 ISRJ-FNet 则结合干扰距离分布的对称先验与目标稀疏结构，并在相同干扰叠加到原目标及距离翻转目标时约束两分支的掩码一致性[R07，PDF p2–3]。因此，本文的出发点不是首次引入物理先验或首次关注保真，而是检验一种具体的干扰估计与残差修正组合：先由观测生成局部窗字典并消去正则化线性系数，再估计结构表示未能解释的剩余干扰。沿用前期含噪参考与共享背景设定，本文进一步区分整体恢复误差和目标增量响应的变化。

### 4.4 讨论：与 FNet/MCA/门控近邻的精确边界

本文与上述近邻的区别在于表示、修正对象和监督接口。ISRJ-FNet 在多脉冲 HRRP 特征上生成软掩码，并约束目标翻转前后的掩码一致；本文在逐脉冲复波形上形成干扰字典，比较固定背景下有无目标时的输出增量[R07，PDF p2–3]。MCA-ADMM-Net 显式联合求解目标与干扰的两组稀疏系数；本文的系数子问题只对应当前生成的干扰字典，并采用正则二次求解，随后由网络补偿残差[R06，PDF p5–9]。此外，IQ-RDNet 已采用全局门控控制保留观测上的残余噪声撤销[R15，PDF p6–7]，故本文不把门控残差这一一般形式作为独立创新。这里的附加修正针对干扰估计误差，参考为同次噪声实现下的无干扰观测。上述差异界定了实现路径，并不自动构成相对近邻的性能优势。

### 4.5 条件分析：最新 SNR/JSR 证据的安全表述

现有条件汇总还包括 Hybrid DEV 与前期 RSDR 主扫描的 SNR、JSR 边际对照。两侧使用相同形式的恢复及目标增量误差，但 Hybrid 是对开发集场景的原生条件均值分桶，RSDR 是对落入同一数值带的固定条件格等权汇总；样本、条件权重和干扰组成均未配对。因此，这些结果仅展示不同评测分布下的描述性读数，不用于判断方法差值的统计显著性，也不能替代同一 DEV 的模型对照。特别是 Hybrid 的高 JSR 端仅有3个基础场景，尚不足以评估重复转发与高 JSR 共同出现时的性能边界。
