# 投稿前实验与模型改进路线

制定日期：2026-11-16（UTC）。这是基于本轮完整稿和已核验结果的后续方案，不是已执行实验的结果。最近一次服务器快照（2026-11-16 08:16:42 UTC）记录既定流水线处于训练阶段；本轮写作收尾未复核实时状态。本文件不启动新训练，不改写已有冻结模型。所有长训练仍只允许在 `rsdr-b` 的第二篇专用目录、物理 GPU 1 执行，每轮保存恢复点，每 32 轮保留里程碑。

## 1. 当前最需要回答的问题

当前研究已经证明单一紧凑校正器能够改善受扰波形，却还没有证明所选骨干比普通同容量网络更合适。三种子 U-Net 的 DEV 五项均值都更好；新模型与旧 RSDR-Net 相比，目标增量失真较小，但背景虚警更高，并在稠密网格和宽度扫描 B 上失去波形误差优势。后续工作的主线应是定位并降低干扰残留，同时保持目标响应，而不是继续增加训练轮数或模块数量。

最短的可靠路线为：完成现有消融 → 复核实现和同容量对照 → 在 DEV 上确定有限候选 → 冻结选择与阈值规则 → 新确认集及等虚警比较 → 同硬件效率 → 按结论范围补稳健性 → 投稿排版。下面每一阶段都有明确的回答对象和停止条件。

## 3. 统计与模型选择的具体口径

**分别报告两类不确定性。** 多种子代表训练随机性，物理 parent 代表场景随机性。同一 parent 下的条件共享 S/J/E，重采样时保留其整组条件；如果对多个 seed 给总体汇总，可报告各 seed 结果及分层重采样，但不能把 seed×条件×parent 当互相独立。三种子只提供有限的训练变异证据，不足以估计稳定的种子尾部风险。

**预先规定主要与次要问题。** 主要检测问题建议设为 J+E 背景下的固定经验帧虚警水平对应的 PD；目标保持问题由目标增量失真与无干扰 NMSE 支持；SJRIF 保留为用户要求的脉压峰比指标。NMSE、相参误差、最强伪峰和效率作为并列补充，不用加权成一个缺少物理解释的总分。具体报警预算和可接受目标保持差异，应由应用需求与现有 DEV 的可测范围确定并在确认前锁定，不能看完确认结果再选界限。

**样本量按要分辨的效应设计。** 对单条件配对检测事件，令 d 为两方法的 PD 差，q 为两方法检测结果不一致的概率，则独立 parent 下差值均值方差为 (q−d²)/n。用已有开发样本估计 q，可据拟识别的最小差异和区间半宽决定 n；共享条件的平均差应按 parent 的聚合差估计方差。n=1,024 时，单个二项概率在最坏 p=0.5 情形的近似 95% 半宽仍约 3.1 个百分点，不能把这样的单条件结果用于确认不足一个百分点的差别。确认集的规模须在上述计算后冻结。

**低虚警需要足量无目标场景。** 建议首先比较经验帧虚警 10⁻²、5×10⁻²、10⁻¹ 的可测范围，且把纯噪声与受扰背景分层。若采用约 10,000 个独立 H0 帧，1% 报警水平下约有 100 次事件，仍需给出二项区间；这是设计量级而非已取得样本。要稳定刻画 10⁻³ 甚至更低报警水平，必须进一步增加独立帧数。零报警不等于零概率：零事件时的 95% 单侧上界约为 3/n。距离–多普勒单元通常相关，不能用单元总数代替独立 H0 帧数。

**阈值必须可部署。** 校准可以用预定混合背景分布构造全局阈值，也可用部署时可观测的分层规则。不能依赖实际不可得的真值 SNR、JSR 或干扰类别给每个 TEST 条件单独调优，再称为通用检测器。若报告按真值条件校准的诊断结果，必须单独标为 oracle 校准，不进入部署排名。

**少做选择，多做确认。** 现有 32 至 256 轮模型全部保留。对原冻结 seed29/128 的历史 TEST 不重命名、不改权重。新的最终模型从 DEV 选择，随后登记独立的新确认身份。若新确认失败，应报告失败并将其转为开发证据；再次改模型需另设确认集。多个主假设可以采用 Holm 等校正，或者预先确定一个主比较，其余明确为探索性；不能事后挑选显著区间。

## 4. 模型如何改：由证据触发的三条分支

### 分支一：先判断固定去斜与骨干是否值得保留

no_dechirp 是最直接的结构诊断。若它在三种子上都降低 J+E 虚警并保持目标增量指标，优先采用更简单的无去斜版本作为候选；若收益只出现在某些输入尺度或干扰宽度，检查归一化、频率搬移和边界处理，而不是立即引入自适应门控。no_rms 用于判断输入尺度处理是否存在不利作用。所有变化先在 DEV 检查，不据一个 seed 的局部最优下结论。

U-Net 同时改变局部块、激活、下采样和去斜。若 A 阶段仍不能解释差异，下一项最有价值的结构实验是固定输入变换与损失，只替换残差块/常规卷积块的最小对照；必要时再单独比较下采样。不要把四种变化全部并入新模型后宣称找到了原因。若普通 U-Net 的优势在新确认中保持，应该接受它作为更合适的骨干，而非保留无证据收益的结构来维持原题目。

### 分支二：针对最强背景残留，而非只降低平均误差

目标增量项可以让两种状态中的相同干扰残留相互抵消，因此较低 D_S 并不约束绝对背景伪峰。若 no_damage 明显提高抑制而损伤目标，应在 DEV 上做有限的权重折中；若 no_pc 对伪峰几乎无作用，说明平均脉压能量约束可能不足以定位少数高峰。先测量残留峰的位置、强度和参考窗污染，再决定是否增加专门损失。

一种可验证候选是在已有三项损失外，针对训练时有真值的目标缺席状态定义脉压残差

\[
r_{\mathrm{bg}}=\mathcal H\{T_\theta(J+E)-E\},\qquad
e_\ell=\frac{|r_{\mathrm{bg}}[\ell]|^2}{\max(N_H^{-1}\|\mathcal H E\|_2^2,\epsilon)}.
\]

其中 N_H 是保留的脉压单元数。用平滑最大值

\[
\mathcal L_{\mathrm{peak}}=
\tau\log\left[\frac1{N_H}\sum_{\ell=1}^{N_H}\exp(e_\ell/\tau)\right],\qquad \tau>0,
\]

使较大局部残差得到更多权重；数值实现需稳定 log-sum-exp。它只是假设性候选，尚未实现或验证，也不等价于最优 CFAR。训练仍保留原端点和目标增量约束，防止通过压低所有输出实现“少报警”。先做单一新增项、有限权重范围、相同训练预算的 DEV 对照，再决定是否值得三种子完整训练。若收益仅来自校准阈值变化而非恢复改善，应优先改检测标定，不增加网络复杂度。

### 分支三：只有失配证据要求时再改相位或上下文建模

当前逐脉冲 I/Q 网络没有复相位旋转等变保证，也不使用慢时间信息。如果新失配测试发现相位旋转、脉间相位或未见转发组合造成系统性退化，可分别研究复相位约束或短慢时间上下文。但这是新的方法范围，会改变参数、延迟与训练数据要求，不应在当前同容量与消融问题尚未解决时同时引入。先以可逆输入相位旋转诊断和跨脉冲残差统计定位问题，再决定结构。

## 6. 投稿决策与时间安排

当前最早能完成的是已有队列收尾和 DEV 消融汇总。服务器快照只证明保存轮次，不保证最终用时；实际 ETA 应用最近完成 epoch 的中位耗时、剩余里程碑评价开销和排队资源重新计算，不能把训练耗时直接当作全部投稿工作的时长。新确认、低虚警样本规模和实测条件尚未冻结，本路线不虚构一个总完成日期。

如果新候选在独立确认中不能优于同容量 U-Net，也没有清楚的效率收益，继续把现有去斜残差骨干写成创新方法，投稿风险仍高。可以将研究定位为紧凑校正框架的系统评估，但仍需清楚区分与第一篇的贡献、数据和文字重叠。若消融能定位有效机制，并在新确认与等虚警比较中复现收益，论文才有更明确的独立方法主线。

正式投稿前，保留本完整技术稿作为母稿，再按目标期刊篇幅把条件风险示意、详细参数计数、优化器展开和扩展统计说明移入附录/补充材料。不能为了压缩删去不利结果、数据角色、基线 oracle 身份或关键适用条件。期刊分区本身不决定证据要求，也不能保证录用。
