# 中文稿 v4 审核与证据索引

2026-11-27。修订对象为完整中文主稿。主要结果固定为种子 17、29、41、53、67 的第 256 轮。本文沿用 v3 的数据与配图，补入已完成的相似性图筛查。

## 与第一篇的关系

写作参照为第一篇 Applied Intelligence 投稿包的作者稿《Reliability-guided selective waveform restoration against interrupted-sampling repeater jamming》，即 2026-11-26 v2 包的 `LaTeX_source/main.tex`。其中摘要先说明为什么保留同一次噪声，引言再介绍模型如何回应这个目标，结果部分分别讨论背景改动和目标响应。v4 沿用这种提问顺序，并以作者稿脚注注明任务定义的来源。卷期和出版状态未作推定。

第二篇沿用同噪声参考、残差输出与四状态配对。新增的研究问题是校正量如何表示。给定字典后，第一阶段的估计可以单独解释；放开字典约束后，精修可能同时改善波形形状并加大幅度衰减。因此摘要没有列出排行榜，结论保留同一模型精修前后的这两个相反变化。普通 U-Net 自身也有较好的幅度保持，冻结 RSDR-Net 在严格低虚警点有优势。参数量只用于说明比较条件。
