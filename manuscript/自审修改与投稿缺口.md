# 自审修改与投稿缺口

审读日期：2026-11-15。目标是检查论证边界、实验身份、统计解释、图表与引用是否和当前证据一致；不是同行评审结论，也不把中文文本分数解释为作者身份或“AI 检测”结果。

## 已完成的自审修改

1. 将论文主张收紧到紧凑单校正器在目标保持任务下的可行性与代价，删弱了“首次提出”及全面优越的暗示。四状态监督和目标增量监督注明沿用作者前期工作。
2. 把信号生成限制写清楚：当前脉冲目标波形作为共享调频模板代理，三类干扰的实现方式依代码实际生成器定义；明确这不是分别模拟雷达—目标及雷达—干扰机传播链路的高保真信道模型。
3. 区分训练端点损失、目标增量损失、NMSE、SJRIF、检测率和经验虚警各自回答的问题。特别说明低目标增量失真不代表干扰被充分去除；SJRIF 不是分离真值下的物理干扰能量改善；名义 CA-CFAR 虚警设定不等于实际等虚警比较。
4. 报告了主网格上新旧模型的双向取舍，并补入稠密网格的 NMSE 排序反转、宽度扫描失效条件、目标保持与背景虚警并存的情况；没有用单张波形图替代配对统计。
5. 将八种子 256 轮结果限定为同一 DEV 上的训练轨迹分析，明确它不能代替独立场景泛化区间。第 128 轮模型的 TEST 身份是在 DEV 选择之后固定，正文不称为查看 DEV 前的预注册。
6. 将等参数 U-Net 和四项逐一消融放在“待完成实验设计”中。它们没有结果时不得用推测填充。由于 U-Net 和消融改变多个因素，结果也需按实际控制变量解释，避免将整体对照误说成某个单独组件的因果效应。
7. 明确 RSDR-Net 统一比较的训练预算及历史环境并未完全匹配，因此可说明冻结系统表现，不能据此断言模型结构本身导致差异。
8. 结论和摘要都说明单目标仿真边界，不宣称实测、真实杂波、多目标、硬件效率、实时性、任意波形泛化或投稿录用等级。

## 论文距离正式投稿的主要缺口

当前稿件已具备完整论文结构、方法数学描述、仿真协议、真实结果、边界讨论和引文；仍是研究初稿，不能直接投稿。至少完成以下事项后再形成投稿版：

1. **完成受控比较。** 等参数 U-Net 三种子训练及无去斜、无 RMS、无脉压损失、无目标增量损失四项消融尚在服务器流水线中。所有任务完成并核对检查点、训练日志摘要、DEV 和新确认集后，更新结果、讨论、摘要和图表。训练任务正在 `rsdr-b` 上运行，不在本地进行。
2. **加入独立确认。** 用未参与训练、DEV 选择、当前 TEST 解释和阈值设计的新 parent 集评估最终冻结模型。父样本配对区间需和 seed 间变化分开报告。若在现有 TEST 上继续选模型，就不能再把它当独立确认。
3. **补足检测公平性。** 在独立校准数据上按明确规则匹配经验虚警率，补充 ROC/等虚警检测比较；当前结果仅是统一名义 CFAR 规则下的检测表现。
4. **稳健性与外部有效性。** 当前是单目标仿真。实测回波、真实 DRFM 转发、杂波、多目标、目标近邻、发射波形失配和跨参数分布尚未验证。结论范围必须与最终实际补做的验证相称。
5. **核验经典基线。** Max-TF、GMM-OMP、BCS 是本地复现；GMM-OMP 尚无独立 DEV 系统调参，BCS 还使用 oracle 支撑。投稿前需复查公式、参数敏感性和公平比较设置，并把 oracle 结果保留为参考上界式对照而非普通可部署基线。
6. **完善统计报告。** 给出配对 bootstrap 的抽样单位、权重、次数和区间定义；补充多重比较策略或明确探索性分析定位。测试条件共享 parent，不能把所有条件简单当成独立样本。小样本相参实验结论需保持限定。
7. **效率与部署证据。** 尚无统一硬件、批量和精度条件下的 MACs、延迟、吞吐、内存测量。只能报告参数统计，不能主张实时、轻量带来具体加速或部署优势。
8. **参考文献与格式。** 投稿前人工核查所有作者拼写、期刊卷期页码、DOI、早期访问状态，以及 L02 元数据；按目标期刊模板统一标题页、摘要字数、图表格式、单位、公式和参考文献格式。
9. **作者信息与研究声明。** 补充作者、单位、通讯作者、基金、利益冲突、伦理/数据声明及目标期刊要求的声明。确认未发表前期稿件 [15] 的引用和重叠披露符合投稿规则。
10. **英文终稿与独立技术校对。** 当前主稿为中文并附英文摘要。确定投稿语言后需专业英文技术润色，并由作者核对每个变量、物理假设、图注及引用上下文。语言润色不能改变数字、公式、限制和作者披露。

## 语言与字符审计

使用 `clean-user-facing-text` 的离线检查流程，只对识别后的自然语言范围检查，不对整稿盲目替换。检查脚本在 `tools/audit_manuscript.py`，运行后报告记录于 `LANGUAGE_AUDIT_after.json`。公式、数值与单位、路径、URL、引用、表格和直接说明按脚本规则保护；任何语言启发式低分均不用于虚构事实、改变科学含义或宣称通过某种 AI 检测。该流程只检查文本可读性与字符异常，不证明作者身份，也不声称清除水印。
