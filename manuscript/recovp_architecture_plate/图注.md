# ReCoVP-Hybrid 模型结构图

**中文图注**　(a) 结构化估计阶段从受扰观测中估计干扰分量，并通过相减得到初步恢复信号。(b) 复值 U-Net 根据初步恢复信号与所估计的干扰提出修正，脉冲门调节该修正对最终输出的贡献。输入端展示仿真观测的实部，输出端下方展示同一记录中的纯净 LFM 参考模板。两条波形分别按自身幅度缩放。(c) 左下图展示与输入波形对应的 3.55–11.43 μs 时窗内的局部字典。每行对应一个原子，按窗内累计能量达到一半的时刻排序，色标表示相对于全字典峰值的局部均方根幅值。(d) 右下图展开复值 U-Net。同一高度的编码块和解码块通过水平跳接相连。尺寸按时间长度 × 复通道数标注，立体网格仅示意特征块。

**English caption**　ReCoVP-Hybrid architecture. (a) Structured estimation produces an interference estimate, which is subtracted from the observation to obtain an initial recovery. (b) The complex U-Net uses both estimates to propose a correction, whose contribution to the output is controlled by a pulse-level gate. The input trace shows the real part of the simulated observation. The clean LFM trace beneath the output is a reference template from the same record. Each trace is scaled independently. (c) The local dictionary covers the same 3.55–11.43 μs interval as the input trace. Rows are ordered by the time at which each atom reaches half its cumulative energy within the window. Color indicates local RMS magnitude relative to the dictionary peak. (d) Horizontal connections link encoder and decoder features at matching resolutions. Dimensions denote temporal length × complex channel count. The grids are schematic.
