独立 TEST 对应冻结的 seed 29、第 128 轮模型。八种子 256 轮曲线用于 DEV 训练稳定性分析；三种子 U-Net 结果也是 DEV 对照。两者不能作为新增的独立确认结果。当前 U-Net 在同容量 DEV 的五项均值上均更好，新模型相对 RSDR-Net 的优势也随指标与测试网格而变化，正文已保留这些结果。
