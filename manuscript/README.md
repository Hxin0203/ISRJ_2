## 证据边界与投稿条件

独立 TEST 对应冻结的 seed 29、第 128 轮模型。八种子 256 轮曲线用于 DEV 训练稳定性分析；三种子 U-Net 结果也是 DEV 对照。两者不能作为新增的独立确认结果。当前 U-Net 在同容量 DEV 的五项均值上均更好，新模型相对 RSDR-Net 的优势也随指标与测试网格而变化，正文已保留这些结果。

论文结构与现有证据已经整理完整，四项三种子消融、六种第二版模型的独立校准/确认及统一硬件前向计时记录均已完成。效率收据记录主机 `DESKTOP-RFFERM3`，但缺少计时代码版本标识，且 `scope` 与现有工作树脚本描述冲突，故稿件将延迟排序标为待核验。投稿前仍需新旧模型的前瞻性校准比较、经典方法源码审计及与投稿主张一致的外部验证，并据结果决定是否进一步改模型。作者信息、基金和期刊格式由定稿阶段补齐；参考文献 [15] 保持未发表前期稿件身份。服务器状态文件仅是文件中标注时间的历史快照。
