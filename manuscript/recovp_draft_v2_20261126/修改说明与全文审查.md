# ReCoVP-Hybrid 论文草稿 v2：修改说明、全文审查与投稿差距

日期：2026-11-26（UTC）。对象：`ReCoVP_Hybrid_中文_draft.md`、`ReCoVP_Hybrid_English_draft.md`。上一版精修稿 `manuscript/recovp_fine_revision_20261126/ISRJ_2论文精修稿.md` 未改动。本轮只改写文稿，没有训练、推理或读取确认集。

## 一、写作规划（先定后写）

叙事主线：ISRJ与目标共享调频结构 → 抑制会损伤目标 → 已有三类方法各自的边界 → 可显式表示的干扰交给可解析模型，表示不了的交给网络 → 两阶段误差的来源决定了精修的必要性 → 目标保真需要单独度量 → 实验从恢复、保真、检测三方面检验 → 讨论取舍与局限。

章节组织参照用户提供的已发表论文：
- CV-FISTA-Net（TAES 2026）与 MCA-ADMM-Net（TNNLS 2026）：“引言—问题建模—方法—实验—结论”，方法部分先给总框架图再逐模块；实验部分先给典型波形与脉压示例，再给统计曲线、消融和检测概率。
- Lei等（IET RSN 2026）：每个子网络配一张层配置表，消融按模块逐项列表。
- CVEDNet（Sensors 2025）：仿真参数表、网络参数表、训练曲线、SNR/JSR扫描曲线。
- ISRJ-FNet（SPL 2026）：“信号模型与结构先验”单列一节，先讲先验再讲网络。
- Conv-TasNet、MPRNet、SFT、EDVR：借鉴“表示—分离—重建”的分工叙述、阶段职责说明和条件调制的写法，不移植其结果。

## 三、AI味道的主要来源与处理

1. 大量“不能…”“不等于…”“并不意味着…”的防御句。按“不能/不等于/并不/不意味/不构成/不代表”计数，原稿54处，本稿18处；证据边界集中写在6.4节。
2. “A承担X，B承担Y”式排比。改为直接说明每个特征或模块解决什么问题。
3. 段落结尾的总结句（“这些结果共同体现了…”）。大多删去。
4. 内部术语进入正文：seed、DEV、checkpoint、归档、收据、同检查点、Stage1Only。改为“训练实例”“开发集”“第一阶段输出”等论文用语；随机种子只在表7占位中出现。
5. 文本审计：两份稿件均无不可见Unicode字符；风格估计器评分中文0.06、英文0.12，均为low档，未触发全文重写。该估计器只是参考，不代表任何检测器的结论。

## 六、实验建议（按投入产出排序）

1. **8种子结果汇总（表7）**：服务器上的8种子流水线完成后直接填表，同时报告均值±标准差和逐种子配对差值。不新增种子。
2. **典型场景图（图5、图6）**：用种子17已有检查点在开发集上导出复数输出，按损伤配对差值的第10/50/90百分位预先选样，不挑结果。同时计算逐场景 $|g-1|^2$ 与形状误差，验证5.4节的解释。
3. **匹配消融（表6）**：优先做(1)单独训练的第一阶段、(3)去掉 $\widehat j_1$ 输入、(5)去掉标量门三项，这三项直接回答“两阶段是否必要”“精修为何要读已撤销干扰”“门是否有用”。每项至少3个种子、256轮。
4. **同协议对比（5.3节占位）**：至少一种传统方法（GMM片段选择或时频滤波）和一种学习方法（CVEDNet或MREDNet按其公开结构复现）。
5. **等虚警检测（表5、图7）**：在独立校准集上定门限，再在评价集报告；扫描门限因子画Pfa–Pd曲线。
6. **算子切换诊断**：对每个场景记录目标加入前后的候选集合与 $\|P_1-P_0\|_2$，验证式（22）对损伤来源的解释（讨论6.2节）。
7. **受控扫描（图9、图10）**：固定其他参数，分别扫描SNR、JSR、采样宽度和受扰脉冲数，按三种转发方式分开。
8. 方法冻结后，按任务书在人工审阅点决定是否启用独立确认集。

## 七、RGSSR V9.1 / V9.2 两份稿件的问题

这两份是codex写的第一篇论文（RGSSR）稿件，与本文是不同的研究，不能合并。阅读后发现的主要问题：

1. **摘要堆满数值**：U-NMSE 1.09876→0.0404545、幅度比0.9032、DEV-Fixed−Flat −7.564508及区间等都写进了摘要，与“摘要只介绍模型”的要求相反。
2. **内部工作语言进入正文**：标题下的“V9.1 · journal-neutral submission candidate… Revised through an internal… not independent peer review”；正文中R3、R5、F6 Stage2 V2、M11、FrozenFlat、“registered”“preregistered”“frozen”等代号；图4段落里“V9.1 renders its original samples as vector paths with 8-point text at 6.8-inch width”属于排版说明，不是论文内容；表2的“6,144 method records”“14,336 four-state diagnostics”是归档计数。
3. **防御性措辞过多**：几乎每段都有“does not establish / is not / cannot”，与本稿原有问题相同。
4. **参考文献格式不统一**：[3]、[6]给出版社链接而没有DOI，二者实际都有DOI（10.3390/rs14143445、10.3390/s25133925）。
5. **V9.2新增的[14]**（Wei等，DSP 2026, 168: 105487）：用户文件夹中的原文已确认DOI与卷号，此前报告中“尚未核验”的说法可以撤销；作者为Wei S, Zhang H, Zhou Y, Zhang L，与稿件一致。
6. **Doppler范围**：附录说明±200 kHz在30 μs PRI下混叠，处理正确；但正文表格仍以±200 kHz描述，读者容易误解，建议在正文就近注明。
7. **作者声明**：V9.2全部为AUTHOR INPUT REQUIRED，未虚构，需作者自行填写。
