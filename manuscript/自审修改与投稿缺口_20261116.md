### 实验结论审查

冻结 TEST 使用 seed 29、第 128 轮模型，权重 SHA-256 为 `7e05f594c26a9c24061216ab4c9cc1e9f264269fb9cbca5e10c27b7690e53cf3`。八种子 256 轮仅用于同一 DEV 的训练稳定性分析。主网格的 168 个条件共享 256 个物理 parent；配对 bootstrap 的抽样单位是 parent，不是把条件当独立重复。当前区间没有多重比较校正，不解释为 seed 总体区间。

结论保留了以下不利证据：主网格新模型的 NMSE 和目标增量失真较低，但 SJRIF、检测与受扰背景虚警弱于 RSDR-Net；稠密网格 NMSE 排序反转；宽度扫描 B 出现较明显检测损失；无干扰改写量比旧模型大。摘要、结果、讨论和结论已同步这些限制。

同容量 U-Net 的种子 17、29、41 均已完成 256 轮。同三种子 DEV 比较中，U-Net 的 NMSE、目标增量失真、SJRIF、检测和背景虚警五项均更好。表 8 已从“未来实验计划”改为真实 DEV 结果，未混入 CorrectionNet 的八种子均值。它同时改变块结构、激活、下采样与去斜，是整体同容量对照，不能用来断言某一个模块有害。此前文件中“U-Net 尚未完成”的说法作废。

截至 2026-11-16 的最新完成收据，U-Net 和 no_dechirp、no_rms、no_pc、no_damage 均已完成三个种子的 256 轮训练。六种第二版模型的独立校准/确认及前向计时记录已生成，证据见 `evidence/outputs/unet_ablation_3seed_256_20261115/PIPELINE_COMPLETE.json`、`EQUAL_PFA_RESULTS.json` 和 `EFFICIENCY_RESULTS.json`。效率收据记录主机 `DESKTOP-RFFERM3`，没有计时代码版本或 SHA，且 `scope` 字段称排除 RMS/去斜，与当前工作树脚本的 `model(x)` 调用描述不一致，因此延迟排序暂不作为已确认结论。08:16 UTC 的服务器快照仅是历史过程记录，不再代表当前队列状态。校准使用 1,024 个 parent，确认使用 2,048 个新 parent；这些证据不包含 RSDR-Net 的新前瞻确认。
