# ISRJ_2 创新候选逐项核验与优化路线

日期：2026-11-17
范围：核对 G:/Files/Markdown/ISRJ_2/gptpro创新性研究.md 与 G:/Files/Markdown/ISRJ_2/ISRJ_2模型思路.md 中的创新设想，并用当前代码、已完成训练与评价记录判断下一步。本文只提出研究决策，不声称候选方法已实现或有效。本轮没有启动训练、改动模型或读取/复制训练权重。

## 结论

目前不应先堆新模块。已有证据指向一个更具体的问题：CorrectionNet 的背景残差能量下降很多时，帧虚警仍然很高；总残差能量不能说明残差是否会被匹配滤波相参积累成检测峰。值得优先验证的主线是：**在相同小型 U-Net 骨干上，让训练目标直接关注目标缺席条件下、经过后级匹配滤波后的大残留峰，同时保留目标增量和无干扰保持约束。** 如果这一训练目标在 U-Net 上有效，贡献应写成检测任务对齐的训练机制，而不是新骨干。

第二优先是检验小网络的局部卷积感受野和频率表示是否匹配脉压器的相参处理增益；可用一个低成本的频率/长时上下文原型与普通 U-Net 做等资源比较。去斜、噪声基准归一化只作为机制因素交叉验证。复相位等变性目前缺乏与实际失效的联系，先做推理期一致性诊断。教师蒸馏暂缓；多脉冲联合建模须等干扰生成器支持可控的脉间相参后再做。

## 逐项判断

| 候选方向 | 当前核验结果 | 结论与进入条件 |
|---|---|---|
| 物理相位/时移等变、坐标一致校正 | RMS 归一化提供正实数幅度缩放等变性，但普通 I/Q 卷积与激活并不保证任意复相位等变。去斜与平移的关系式成立；等变误差是否关联当前失败尚未测量。旧 TEST 上的整体目标相位偏差很小，不能代替输入变换一致性测试。 | 先对冻结模型做公共相位旋转和带边界余量的整场景时移测试，并与同等增强的 U-Net 对照。恒等输出也可以完美等变，因此必须同时看校正性能。诊断与检测/目标失真无关时，不做等变骨干。 |
| RSDR-Net 选择性蒸馏 | 同一旧 TEST 诊断显示教师的背景抑制优势随输入绝对幅度变化；低 JNR 也有不动作区，且教师并非目标保持方面的稳定优胜者。普通输出模仿可能同时迁移幅度压缩或形状误差。 | 暂不作为主线。只有在新 DEV 上确认教师的某个背景抑制能力跨幅度、干扰类型稳定，并且普通蒸馏无法解释收益时，再比较真值训练、输出蒸馏、校正量蒸馏和选择性蒸馏。教师只在训练期使用。 |
| 多脉冲联合/低秩或时序结构 | 现有网络按单脉冲前向；paper2/scenes_1103.py 为各脉冲独立抽取干扰随机流。当前数据不能代表可控的脉间相参转发干扰。相参目标可形成跨脉冲结构，但相参干扰也可能低秩。 | 暂缓。先修订并验证生成器，加入独立、部分相参、强相参干扰模式；再与同样读取完整脉冲组的 U-Net 对照。没有这一步，现有模拟器上的跨脉冲胜出可能只是生成器捷径。 |
| 背景残留尾部 / 匹配滤波峰值损失 | 这是当前候选中有最直接证据的一项。JNR 30 dB 时，RSDR 的残差/干扰能量比约为 CorrectionNet 的两倍，但帧虚警约为 5.2% 对 37.1%。旧 TEST 上 CorrectionNet 的背景残差能量可低至干扰的 −30 dB 以下，虚警却随 JNR 明显回升。现有 L_pc 是归一化脉压误差能量，不是目标缺席背景的最大峰或尾部约束。 | 排第一做 DEV 小试验。令 T(Y)=Y−C(Y)，目标缺席背景误差 r_bg=T(J+E)−E=J−C(J+E)。对 H r_bg 的帧内大峰或平滑最大值施加噪声脉压功率归一的损失；不能惩罚输出总功率。保留 endpoint、damage、无干扰保持。与现有平均 L_pc、困难样本重加权对照。该代理损失不等于 CFAR，也不保证固定虚警。 |
| 增大相参处理增益：长时核/谱分支/降采样处理 | 失效分段与后级匹配滤波的相参增益相符；卷积路径感受野有限，计算主要集中在全分辨率层。但“感受野不足”尚无消融因果证据。当前等参数 U-Net 整体优于 CorrectionNet，说明旧的复杂外壳不值得默认保留。 | 排第二做最小骨干实验：普通 U-Net 对照一个等参数且尽量等 MAC 的降采样分析—频率处理—合成校正器。预先固定输入坐标与损失。若只改变多个模块，将无法归因。按 JNR 逐点看虚警与目标损伤，不只看平均 Pd。 |
| 去斜与骨干坐标交互 | No dechirp 结果优于 full，但“去斜让频带随时间旋转、短核卷积难利用”的解释目前是机制假设。对易关系可推导，不代表它是退化原因。 | 用 {原始, 去斜} × {短核, 长核/谱处理} 的小型交叉设计检验。若长/谱处理无法挽回去斜收益，或差异只由容量/训练差异解释，则不主张坐标一致创新。 |
| 噪声基准归一化替代 RMS | 绝对 RMS 归一化会消去输入总体幅度线索，RSDR 对幅度敏感；由带外噪声估计恢复噪声基准在理想带限仿真中可行。但真实接收机、带外杂散和滤波器会改变估计可靠性。 | 作为低成本单因素实验。与 RMS 统一尺度、训练数据和阈值规则；加噪声估计误差/带外污染敏感性。不能以“归一化更物理”代替性能证据。 |
| 两次共享权值递推校正 | 与强 JNR 下单次预测的相对残差平台相符，但目前只是 H2。重复前向会增加延迟，且第二次校正输入分布不同。 | 排在谱/长时模块之后。先仅测试固定模型的迭代稳定性；若有效，再重新训练共享两步模型，并报告完整延迟、目标损伤和是否发散。 |
| 扩训练 parent、Main/Extreme 训练或报告 | 现有训练有 256 Main + 256 Extreme 参数分层，但优化时混合抽样，未按 profile 单独报告。DEV 是宽范围混合角色，没有 Main/Extreme 标签。DEV 中 parent 平均 SNR 四分位边界约为 −10.73、−7.35、−4.52 dB；四组各 64 个，平均 SNR 低于 −20 dB 的 parent 为 0。按该 DEV 不能冒称独立 Extreme 评估。 | 后续新建角色隔离的 Main/Extreme DEV 和校准/确认数据，分别报告；当前 DEV 只按实际 SNR/JSR 分位作探索性分层。扩大训练集可以检验小数据归纳偏置，但不是独立方法创新。 |
| 简化/重参数化轻量骨干 | 当前 CorrectionNet 和 U-Net 均为 59,714 个有效参数；现有测量 U-Net 单波形更快（约 2.20 ms vs 3.39 ms），而 Conv1d MAC 只差约 3%。因此“参数少”等于“轻量”的论据不足。 | 把 U-Net 作为默认骨干候选。只有同时报告完整前向延迟、整脉冲组延迟、MAC 范围、峰值显存与设备后，才作轻量结论。可借鉴训练期分支、部署时折叠，但目前 CorrectionNet 中输入相关归一化/非线性不能被精确折叠。 |

## 现有 DEV 的正确读法

DEV 共有 256 个物理 parent，SNR 在 8 脉冲间抽样。用每个 parent 的 8 脉冲平均 SNR 排序，四分位各 64 个。seed 17/29/41、epoch 128 的描述性汇总中，四组平均受扰帧虚警约为 12.15%、16.49%、13.19%、20.31%；目标检测率约为 68.92%、85.24%、90.80%、99.13%。这些组是按 DEV 实际 SNR 划出的诊断分组，不是预先冻结的 Main/Extreme 角色，且该 DEV 已参与开发，不能充当新确认集。

这也说明总体 Pd 容易被目标 SNR 构成影响，必须把 Pd 与目标缺席 Pfa 分开看，并按 parent 保持四状态、脉冲与干扰类型的相关结构重采样。U-Net 的逐 SNR 四分位结果目前没有从已同步的轻量汇总中核验，不能把上述分组趋势直接推广到 U-Net。

## 推荐优化流水线

**阶段 0：锁定证据边界。** 冻结现有模型、源码和数据摘要。现有 TEST/确认只用于诊断；不再作为新方法的盲确认。当前 DEV 可做探索，不切成伪 Main/Extreme。新方法的最终评价需另造不重叠的校准和确认 parent。

**阶段 1：只做推理期诊断。** 在同一 parent 上补齐 Full、U-Net、No-dechirp、No-RMS、No-PC、No-damage 的逐 JNR/JSR 目标缺席虚警、背景误差匹配滤波峰值、目标增量失真和 Pd。按实际 SNR/JSR 分位另列探索表。检查相位/时移等变误差是否与失败指标关联。结果决定 H1、H3、H4 是否进入训练。

**阶段 2：U-Net 上的损失筛查。** 同一骨干、样本、优化器、训练更新数和 seed 做两项小规模独立对照：A) 现有目标；B) 现有目标加目标缺席背景的匹配滤波尾部项。先用少量共同 seed 筛查，按 DEV 方差与资源预注册保留或停止；不同时添加蒸馏和架构变化。指标含每 JNR 帧 Pfa、目标增量误差、无干扰修改、背景峰尾分位数及效率。

**阶段 3：结构和归一化验证。** 仅对阶段 1/2 有证据支持的因素做小型交叉实验：普通坐标/去斜坐标，短时局部块/降采样长时或谱分支；另独立替换 RMS 为带外噪声基准。以等参数与等 MAC 的 U-Net 为控制，不能将多因素一起改后归因。

**阶段 4：合并与独立确认。** 只合并通过 DEV 门槛的因素。比较检测—目标保持前沿，不挑单一最有利工作点；在新校准集冻结阈值，在新确认集报告实际帧虚警和 Pd 区间。Main/Extreme 必须由生成参数和角色配置预先定义。训练长任务只在服务器 B、D:/code/Xin/ISRJ_222、物理 GPU 1 执行，每轮保留恢复点和 32 轮里程碑。

**阶段 5：扩展边界。** 只有多脉冲生成器加入可控相参模式后才测跨脉冲结构；只有教师优势在新 DEV 上跨幅度稳定后才测蒸馏。所有近邻工作需补全文方法差异表，尤其是 2026 年 ISRJ-FNet、MCA-ADMM-Net、MoRPCA、复数 FISTA-Net 等。现有文献审查是定向梳理，不能据此声称穷尽查新或“首次”。

## 决策结论

当前最可执行的优化方向是**匹配滤波风险对齐的背景尾部训练目标**，其次是**让轻量骨干获得与检测链相符的长程/频率处理能力**。先将前者放到强 U-Net 上验证，再决定是否需要改骨干。这能回答一个真正重要的问题：当前失败来自损失与评价目标不一致，还是小网络缺少相参处理能力。

物理对称、选择性蒸馏、多脉冲分解仍有研究空间，但现有证据不足以把它们列为这轮主线。若尾部目标和长程模块都未能在公平预算下改善虚警—目标保持前沿，就不继续加模块，应据实将第二篇定位为失败区间分析和可靠折中，而不是硬造一个新网络名。
