## 指标含义与条件口径

第一篇定义的 $e_U=||T(Y_{11})-U||_F^2/||U||_F^2$ 与两边评测实现的 `u_nmse` 完全同式。第一篇的 $e_S=||D_T-S||_F^2/||S||_F^2$ 与 `damage` 完全同式，均按目标增量计算。因而这两项可按同一指标名称对照。`pd` 是目标帧检测率；`frame_pfa_jammer` 是目标不存在、只有干扰与噪声时的整帧虚警率；`sjrif_db` 即脉压后的信号干扰比改善因子 SJRI-F。

Hybrid 按 DEV 每个 parent 的原生 SNR 均值分 5 dB 桶、按干扰脉冲/干扰变体聚合后的 JSR 均值分 10 dB 桶，指标为 parent 平均并给 parent bootstrap 95% 区间。RSDR 侧对第一篇主扫描落入同一数值桶的精确条件点估计等权平均，跨 3 类干扰汇总；括号中的条件数是该带内 RSDR 的精确条件格数，每格 256 个场景。两边不是共享 parent 的配对比较，RSDR 聚合区间也未从逐格区间拼造。

## 总体读数与结论

- e_U / u_nmse：Hybrid DEV 0.0431（95% CI 0.0371–0.0495）；RSDR-Net 主扫描 168 格等权均值 0.1023。
- e_S / damage：Hybrid DEV 0.0597（95% CI 0.0517–0.0687）；RSDR-Net 主扫描 168 格等权均值 0.0718。
- P_d：Hybrid DEV 87.1%（95% CI 83.2%–90.9%）；RSDR-Net 主扫描 168 格等权均值 68.0%。
- 受扰帧虚警率：Hybrid DEV 5.6%（95% CI 3.9%–7.4%）；RSDR-Net 主扫描 168 格等权均值 7.1%。
- SJRI-F (dB)：Hybrid DEV 11.10（95% CI 10.29–11.85）；RSDR-Net 主扫描 168 格等权均值 4.74。

在当前可直接读取的结果中，Hybrid seed17 的 DEV 总体 `u_nmse/e_U`、`damage/e_S`、SJRI-F 与检测率点估计优于 RSDR 主扫描格均值；干扰帧虚警率也略低。分层结果提示这种优势主要出现在 DEV 覆盖的中低 SNR 与中等 JSR 区域。这个方向值得继续，但还不能作统计显著或全条件优越结论：Hybrid DEV 与 RSDR 168 格不是共享 parent，条件权重和覆盖不同；Hybrid SNR 只覆盖 5 个桶，JSR 两端各只有 2–3 个 parent。特别是低 SNR、JSR≥30 dB 区域，需对 Hybrid 在完整 168 格上按同一场景生成器进行推理，并按干扰类型给出逐格结果，才能严谨复核第一篇曲线。
总体 `damage/e_S` 仍约 0.060，说明目标增量误差尚不可忽略；检测率提高必须和受扰帧虚警率同时解读。SJRI-F 会受目标峰及相邻距离单元影响，按第一篇文稿自身的说明，低 JSR 条件下还应结合误差和虚警率理解。
