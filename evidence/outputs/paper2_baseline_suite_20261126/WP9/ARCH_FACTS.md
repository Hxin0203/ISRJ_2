# WP9 ReCoVP-Hybrid 结构核对（对照源码）

源码：`tools/vp_1103_recovp_hybrid.py`（本文件与服务器 B 上训练所用版本逐字节一致，见 2026-11-26 依赖核对）。行号均指该文件。

## 1. 候选时延与窗网络

- **候选时延 τ_k 不是学出来的。** `_rect_k16_anchors`（第 85–106 行）在匹配滤波幅度响应上贪心挑选 K=16 个局部峰，互相间隔至少 6 个采样点（第 103 行），在 `torch.no_grad()` 下进行。
- **时延有一个小的学习修正。** `refine_head` 输出 $\Delta\tau_k=2\tanh(\cdot)$，即每个候选最多移动 ±2 个采样点（第 177–179 行）：$\tau_k=\text{anchor}_k+\Delta\tau_k$。
- **窗网络只输出窗形** $w_k\in[0,1]^T$，不改时延（第 118、195–198 行）。输入是共享编码器特征，加上去斜量 $z_k=x\odot t_k^*$ 在 5、15、31 点平滑后的幅度与一阶滞后积（9 个物理通道）。窗经 sigmoid、3 点平滑，再按峰值归一化（下限 0.05）。
- 原子 $\phi_k=w_k\odot t_k(\tau_k)$，再归一化到单位范数（第 199–202 行）。

## 2. 系数求解

带正则，而且正则是**学出来、逐原子、随数据变化的**（第 203–220 行）：

$$\hat c=\big(\tfrac12(G+G^H)+\operatorname{diag}(\lambda)\big)^{-1}\Phi^H x,\qquad G=\Phi^H\Phi .$$

- $x=y/\mathrm{RMS}(y)$；噪声方差 $\hat\sigma^2$ 由三步 Weiszfeld 鲁棒中心加中位数绝对偏差估计（第 203–207 行）。
- $\rho_k=|\phi_k^H x|^2/\hat\sigma^2$ 是每个原子的匹配能量相对噪声之比（第 208 行）。
- $\lambda_k=10^{-4}+\exp\!\big(30\tanh(\ell_k/30)\big)$，$\ell_k=\text{head}_k+2(\ln 9-\ln(1+\rho_k))$（第 211–213 行）。$\rho_k$ 越小，$\lambda_k$ 越大，弱原子被收缩得越多。
- 求解在 complex128 下进行；修正 $c=\Phi\hat c\cdot\mathrm{RMS}(y)$，$u=y-c$（第 219–221 行）。

## 3. 门 α

- 每个脉冲一个标量 $\alpha=\sigma(\text{MLP}(\cdot))\in(0,1)$（第 297、351–352 行）。
- MLP 输入 20 维：6 个不变特征各自的均值、标准差、95% 分位（18 维），加两个物理标量：修正能量与观测能量之比的对数，以及第一阶段残余匹配滤波输出的峰均比的对数（第 343–351 行）。
- 最后一层偏置初始化为 −3，即训练开始时 $\alpha\approx0.047$（第 298 行）。
- 最终输出：$\hat x=u-\alpha\,\delta$，其中 $\delta$ 是精修网络的原始输出乘以 RMS（第 353、375 行）。**注意符号是减号。**

## 4. 精修网络

- 输入：两个复通道，第一阶段残余 $r=u/\mathrm{RMS}$ 与修正 $j=c/\mathrm{RMS}$（第 329 行）。原始观测 $y$ 不直接进入卷积，只通过 α 的一个物理标量参与。
- 结构：三层复值 U-Net，通道宽度 9/13/17/21（第 32 行）。stem → enc0（残差）→ enc1 → enc2 → 瓶颈三块（膨胀 1、2、4，均为残差）→ dec2 → dec1 → dec0 → 1×1 复卷积输出（第 280–298、330–341 行）。下采样为复平均池化，上采样为复线性插值，编码与解码之间有拼接跳连。
- 每块：无偏置复线性卷积（第 228 行），后接由幅度和 6 个不变特征算出的实值 sigmoid 门（第 260 行）。
- 6 个不变特征：残余和修正的对数幅度、残余的一阶滞后积（实部和虚部）、残余与修正的互积（实部和虚部）（第 307–316 行）。

## 5. “等变”的含义

对**任意非零复标量**等变：$f(c\,y)=c\,f(y)$，同时覆盖幅度缩放和相位旋转。依据：RMS 归一化是一次齐次的；锚点只依赖 $|{\rm MF}(x)|$；窗、$\rho$ 和 $\lambda$ 都只依赖幅度和滞后积，后者满足 $(e^{j\theta}x_n)(e^{j\theta}x_{n-1})^*=x_nx_{n-1}^*$；系数求解对 $x$ 线性；精修网络只用无偏置复线性卷积，门只看幅度。

- 对锚点顺序置换不变（预检误差为 0）。
- **不是**时移等变：位置特征、锚点的边界约束和固定的 $T=1800$ 都会破坏时移等变。

## 7. 结构图草案需要改的地方

| 草案写法 | 实际 |
|---|---|
| 窗网络输出窗 $\{w_k\}$ 和时延 | 时延由匹配滤波峰贪心挑选（不学习），另有 ±2 点的小修正头；窗网络只输出窗形 |
| 系数用纯最小二乘或单一 $\lambda$ | 逐原子、随 $\rho_k$ 变化的学习型 Tikhonov 正则 |
| 门 $g$ 的输入为 $u$ | 门的输入为不变特征的统计量和两个物理标量；每脉冲一个标量 |
| $\hat x=u+g\delta$ | $\hat x=u-\alpha\delta$ |
| 精修网络画成通用的 “CConv block” | 三层复值 U-Net，9/13/17/21 通道，瓶颈膨胀 1/2/4，每块为复线性卷积加幅度门 |
| 精修网络的输入为 $u$ | 输入为两个复通道：残余 $r$ 和修正 $j$ |
| “相位等变” | 复标量等变（幅度和相位），并对锚点顺序置换不变 |

## 8. 对论文论证的影响

推论 1 的 $K/T$ 上界只对**与数据无关的固定字典**成立。这里的锚点是在观测本身的匹配滤波峰上挑出来的，属于数据自适应的选择，即使输入是纯噪声，投影也会偏向噪声中恰好较大的方向，带走的能量可以超过 $K/T$。所以模型实际的背景改动小，可能主要靠随 $\rho_k$ 变化的收缩，而不是 $K$ 的硬预算。WP8 的 `stage1_K*_noreg` 与 `stage1_K*_learned` 对比直接检验这一点。
