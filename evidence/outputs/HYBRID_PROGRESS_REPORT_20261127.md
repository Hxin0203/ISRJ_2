## 已获得的性能结果

等虚警评测使用独立校准集 1024 场景和评测集 2048 场景，以下统一采用标称帧 Pfa=1% 的校准门限。Hybrid 为 4 个 seed 的均值，UNet-Tail 和 CorrectionNet 为 3 个 seed，RSDR-Net 使用第一篇冻结的单个训练实例。

| 方法 | seed 数 | 检测率 Pd | 实测干扰帧 Pfa | 目标损伤 |
|---|---:|---:|---:|---:|
| ReCoVP-Hybrid | 4 | 55.81% | 0.91% | 0.05892 |
| UNet-Tail | 3 | 52.71% | 0.85% | 0.04709 |
| CorrectionNet | 3 | 47.11% | 0.86% | 0.06094 |
| RSDR-Net | 1 | 73.50% | 0.93% | 0.0909 |
| CVEDNet | 1 | 91.78% | 0.94% | 0.6465 |

Hybrid 比 UNet-Tail 高 3.10 个百分点，场景配对 bootstrap 95% 区间为 [+2.63, +3.62]；比 CorrectionNet 高 8.71 个百分点，区间为 [+7.84, +9.61]。Hybrid 的 Pd 种子间标准差为 2.12 个百分点，仍需其余 4 个 seed 才能形成完整的 8 种子统计。场景区间不能代替训练种子不确定性。

Hybrid 比 RSDR-Net 低 17.69 个百分点，区间为 [-19.02, -16.34]，但目标损伤更低。因此，目前的证据支持 Hybrid 相对于普通学习基线的检测改进及目标保真优势，不支持“全面超过第一篇模型”。CVEDNet 检测率较高，但其目标损伤和无干扰改动较大；该冻结权重监督目标与数据分布不同，须连同保真指标解释。

DEV256 的完整逐场景统计目前仍主要对应 Hybrid seed17，不能冒充 4 种子 DEV 均值：

| 指标 | Hybrid seed17 | RSDR-Net 冻结实例 |
|---|---:|---:|
| u_nmse，越低越好 | 0.04312 | 0.03343 |
| 目标幅度比，越接近 1 越好 | 0.9152 | 0.8905 |
| 目标损伤，越低越好 | 0.05967 | 0.0947 |
| SJRI-F | 11.10 dB | 11.34 dB |
| 名义 CFAR 检测率 | 87.11% | 86.98% |
| 干扰帧虚警率 | 5.599% | 5.078% |

DEV 名义 CFAR 下二者检测率相近，但在严格等虚警评测中出现明显差距。这两套数据与门限口径不同，不应混用检测率或据此宣称矛盾。

SNR×JSR 扫描已完成：8 档 SNR（-25 至 10 dB）、4 档 JSR（0、10、20、30 dB），32 格，每格 64 个物理场景，共 2048 个，与 TRAIN、DEV、确认集和两套等虚警集的场景 ID 重叠均为 0。Hybrid 已纳入 17/29/41/53。名义 CFAR 下，SNR=-20 dB、JSR=30 dB 时 Hybrid 检测率为 93.4%，RSDR-Net 为 93.8%，普通 U-Net 为 91.3%；SNR=-25 dB、JSR=30 dB 时分别为 24.6%、26.0%、21.4%。这说明极低 SNR 仍是主要短板。这些扫描点没有逐格重新匹配实测虚警率，不能当成等虚警优势。

## 后续自动步骤及未完成项

服务器评测总控处于 FOLLOW_HYBRID，已包含 17/29/41/53，每 30 分钟检查新完成的 seed，并接入等虚警评测及 SNR×JSR 扫描后重新汇总。总控有从启动起 96 小时的跟进期限，不是永久监视。原 8 种子控制器仍负责全部训练回执齐全后的标准 DEV256 评测。

仍未完成：剩余 4 个 seed 的完整训练；8 种子完整统计；其余 seed 的标准 DEV256 逐场景统计；统一计算耗时；典型场景波形、脉压和 RD 图；残余相干度分布图；切片宽度与未受扰比例扫描。后两类条件扫描需要生成器新接口。独立确认集尚不能据本次进度核查宣布完成。

本次核验了已配置 seed 的源文件 SHA，17/29/41/53/67/97 均无不匹配。4 个完成 seed 各有 257 个恢复点的 SHA 回执（epoch_000 至 epoch_256）；另独立重算了这 4 个 seed 的 epoch_256、seed67 的 epoch_191 和 seed97 的 epoch_000 检查点 SHA，均与对应回执一致。本次未重新读取并核算所有历史检查点及整个训练数据；新启动 seed97 的预检和训练入口会核验其源文件与数据绑定。新增恢复控制器测试与既有分队列测试合计 5 项通过。

阶段结论：训练已完成一半 seed，双 GPU 已恢复同时训练；Hybrid 相对 U-Net/CorrectionNet 的等虚警检测优势已在 4 种子汇总中出现，但相对 RSDR-Net 仍存在严格低虚警检测差距。当前应保持冻结模型与评测口径，完成剩余种子，再判断训练稳定性和最终论文结论。
