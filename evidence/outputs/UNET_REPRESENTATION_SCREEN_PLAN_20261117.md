# 长程卷积与频域表示：独立筛查预设方案

本方案在读取这两组结果前固定。两组均为开发筛查，不是新模型已有效的证据；不因尾部损失或归一化是否通过筛查而改变其定义。

| 因素 | 唯一改动 | 设备和前置任务 | 能回答的问题 |
|---|---|---|---|
| dilation | U-Net 五个双卷积块的 dilation 为 1、2、4、2、1，padding 同步；权重形状不变 | 服务器 B，物理 GPU 1；尾部损失三种子训练和 DEV 评价完成 | 扩大卷积采样跨度能否改善相干残差；不能声称首次获得全局信息，GroupNorm 已跨时间统计 |
| frequency | 输入复数正交 FFT、fftshift，经原 U-Net 输出校正量后 ifftshift、正交 IFFT | 服务器 B，物理 GPU 0；归一化三种子训练和 DEV 评价完成 | 频域坐标是否更易由同容量骨干拟合；不能直接等同于学习型频率模块、相位等变或所有频率方法 |

两组都维持输入 RMS、原始 endpoint + 0.1 PC + damage 损失、59,714 个活动实参数、相同初始张量、相同 512 个训练 parent、相同 DEV、seed 17/29/41、每种子 256 轮与 12,288 次更新、Adam 和学习率计划、FP32/关闭 TF32。没有新增尾部损失、蒸馏或多脉冲输入；FFT 在每个脉冲内独立执行。FFT 的数值误差不改变统一的数值下限定义，极小输入下不主张精确代数等价。

冻结 epoch 256 与普通 U-Net 配对评价，不挑最好种子或轮次。报告完整 loss 分量、NMSE、目标增量损伤、无干扰修改、SJRIF、Pd、纯噪声与受扰背景实际虚警。三类干扰先在同一 parent 内平均；不把脉冲或家族当成独立样本。

筛查门槛与已运行两组一致：三种子受扰背景帧虚警变化的中位数 < 0；每种子 Pd 变化 ≥ −0.02；平均目标损伤变化 ≤ +0.005。它是资源筛选规则，不是显著性检验或已证明的非劣效界。若仅虚警下降且目标保持越界，标为失败；均值改善但种子方向不一致，列为不稳定。通过后仍需独立校准、确认和效率测试。

队列启动即冻结源码 SHA。依赖任务须生成匹配 SHA 的 DEV 汇总与完成收据；失败、源码漂移、数据／模型收据不符时停止，不绕过。资源准入连续三次要求 GPU 利用率 < 20%、可用显存 ≥ 12 GiB、CPU < 85%、可用内存与磁盘均 ≥ 8 GiB。GPU 忙时等待，不终止其他进程。

正式训练前在服务器上检查：FFT 往返与 Parseval、活动参数、三种子初始张量、有限前反向、模型／优化器／RNG 恢复及下一步数值一致性。GPU 检查未通过前不能标为已预检或训练中。每个完成轮次原子保存恢复模型、优化器、随机状态和分项损失；每 32 轮另存里程碑，既有模型不覆盖。每个筛查控制器有 96 小时累计预算及 STOP/PAUSE 控制。意外中断后重启同一入口并核验 SHA；不会自动重训并吞掉失败记录。

两类因素暂固定到不同 GPU，因此单个比较可能含设备运行差异。设备同型号且精度设置一致仍不等于完全消除该差异；最终候选和控制须在统一设备、相同计时范围复核，必要时交换设备重复关键比较。三种子筛查只估计开发趋势。

若两组均无收益，不增加更多模块维持故事；返回变换一致性和共同 DEV 上教师优势诊断。多因素组合、跨骨干四格、平均 PC／困难样本对照、新校准集和新确认集均属于后续阶段，未由本队列自动执行。
