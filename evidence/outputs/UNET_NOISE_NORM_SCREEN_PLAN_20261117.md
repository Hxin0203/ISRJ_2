# GPU 0 独立归一化筛查方案

本方案在训练前固定。用户于 2026-11-17 明确授权使用服务器其他空闲显卡并行实验，因此将原来的顺序筛查调整为两个独立分支。GPU 1 的尾部损失实验继续运行，其冻结源码、配置、检查点和评价规则均保持原样。GPU 0 运行本方案，不把尾部损失的中途训练数值用于设计或选择归一化设置。

## 研究问题与对照

检验显式提供观测噪声尺度能否改善普通 U-Net 的受扰背景虚警，同时保持检测能力和目标保真。RMS 归一化并未在信息论意义上抹去 JNR：归一化后的频谱仍含噪声相对功率信息。本实验检验的是将这一信息显式提供给有限容量网络的效果，而不是证明 RMS 必然丢失信息。

唯一改动为输入和输出共用的归一化尺度。三个种子 17、29、41，各从与既有普通 U-Net 完全相同的初始参数训练至 256 轮；每轮 512 个 parent × 3 类干扰、48 次更新、每批 32 条记录，分成 4 个微批累积。优化器、学习率、FP32 设置、原端点损失、脉压损失和目标增量损失保持不变，不增加尾部损失。参数量仍为 59,714。两张卡型号相同，跨卡浮点环境仍须记录，不宣称轨迹逐位相同。

## 固定的观测尺度

采样率为 60 MHz，波形长度为 1800。对每条 I/Q 波形独立计算单位归一化 DFT，在固定频带 |f| > 22.5 MHz 上取功率中位数，定义

\[
\widehat\sigma(y)=\max\!\left\{
\sqrt{\operatorname{median}_{|f_k|>22.5\,\mathrm{MHz}} |\mathcal F_u y[k]|^2/\ln 2},
10^{-4}\operatorname{RMS}(y),10^{-8}\right\}.
\]

复白高斯噪声的谱功率服从指数分布，人口中位数为均值的 ln 2 倍，因此该估计提供复噪声 RMS 的代理。有限样本中位数存在小偏差。采用 22.5 MHz 的固定边界是为了在名义 ±15 MHz 信号带外留出保护区，不扫描频带或分位数。有限时长、切片和转发边缘会产生带外泄漏，该区域不能视为纯噪声，估计也不能称为真实噪声测量。

网络执行 C(y) = σ̂(y) U(y/σ̂(y))。除绝对数值下限附近外，该尺度对非零实幅度满足 σ̂(ay) = |a|σ̂(y)；网络对正幅度缩放具有相应等变性。不得据此声称网络相位等变。估计器仅接收本条观测波形，不接收真实噪声、干扰、SNR/JNR、支撑或其他脉冲的信息。标签只用于既有监督目标和单独的离线泄漏诊断。

## 预检、保存与执行

长训练仅在服务器 B 的 D:/code/Xin/ISRJ_222 执行，物理 GPU 0，UUID GPU-f12e73b1-3bed-5a1e-bcb0-f9726dd1621d。新执行入口独立守卫主机、目录和设备；不得修改 GPU 1 入口的守卫。启动前连续检查资源；其他任务占用时等待，不终止其他任务。

预检固定检查 2048 条单位功率复高斯噪声的尺度校准、正幅度等变、零输入、三种子初始参数与冻结 epoch-0 的逐张量一致性、所有参数参与前反向、优化器和 RNG 的断点恢复。加载的模型与优化器状态要求逐张量一致，RNG 要求一致；恢复后下一步模型参数和各损失采用绝对容差 10⁻⁶，不要求后续浮点计算逐位相同。记录前 32 个训练 parent 的目标及干扰带外泄漏比，不根据该结果调整估计器。预检不读取 DEV 性能。

冻结源码、方案、数据、预检、对照检查点与配置 SHA。每个已完成 epoch 保存完整模型、优化器、RNG 和各损失分量；保留 epoch 0–256 的恢复点及 32/64/96/128/160/192/224/256 里程碑。恢复先验证 SHA 和身份，不覆盖已完成模型。STOP/PAUSE 和累计 96 小时预算控制仍适用。

## 评价与后续决策

三个种子训练全部结束后，在固定 DEV 上对每个种子的 epoch 256 与既有同种子普通 U-Net 配对比较。报告整体误差、端点/脉压指标、目标增量误差、SJRIF、检测概率、纯噪声和受扰背景帧虚警；各 parent 内先平均三类干扰，不将其视为独立样本。训练曲线用于说明优化过程，不等同于泛化性能。

筛查通过规则与尾部损失分支保持一致：三个种子的受扰背景帧虚警变化中位数 < 0；每个种子的检测概率变化 ≥ −0.02；三个种子的目标增量误差变化均值 ≤ +0.005。所有种子如实保留，不挑最好种子或轮次。此为方向筛查规则，不是显著性或非劣效性证明；三种子结果应分别展示。

本分支与尾部损失分支独立，后续长程/频率单因素可以继续按预注册方案安排；只在因素筛查完成后讨论组合。任何最终组合需在新生成且未参与开发的确认 parent 上评估，DEV 不作独立确认。若带外泄漏严重或筛查不通过，保留负结果，不用确认集修复估计器。
