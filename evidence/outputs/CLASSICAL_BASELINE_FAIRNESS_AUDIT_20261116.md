# 经典基线公平性审计与待执行校准

审计日期：2026-11-16。本文依据本地冻结适配器、来源与公式审计、既有 1103 主网格结果及当前论文表述整理。它区分已核验事实、已完成的旧结果和仍需执行的实验；不将本地复现结果解释为原论文方法的性能上限。

## 已核验的实现边界

| 方法 | 当前输入信息 | 本地实现核验 | 主要公平性限制 |
|---|---|---|---|
| Max-TF | 接收波形、公开发射波形参数 | 按来源论文时频能量、最大时频轮廓、分段阈值、掩模扩展及滤波链实现；离散峰并列处理、平滑规则是本地选择 | 复现选择会影响输出；目前用固定配置，尚未以 DEV 选择参数 |
| GMM-OMP | 接收波形、公开发射波形参数；不使用标签或干扰真值 | 两分量幅度 GMM、干净采样选择、去斜及 Fourier OMP；责任度加权方差按标准 EM 更新 | 稀疏度、迭代设置和分类掩模对结果敏感；打印公式存在已记录的更新差异；目前固定配置，尚未以 DEV 选择参数 |
| BCS | 观测加真实非干扰支撑 | 使用平滑稀疏 MAP、外层重加权和内层复数共轭梯度 | 真实支撑带来部署时不可得的 oracle 信息；只能单列为 oracle 参考，不得作为同信息条件的竞争算法 |

旧测试结果显示 GMM-OMP 的受扰背景帧虚警接近 100%。该数字只对应冻结本地实现、固定配置和该测试扫描，不能据此声称 GMM-OMP 方法类失效。Max-TF 和 GMM-OMP 当前结果也不能代表经充分参数选择后的实现上限。BCS 的较强脉压抑制需连同 oracle 支撑条件解释。

## 数据和比较规则

后续经典法参数选择只使用 `paper2_1103/dev.npz`，不读取或据独立 TEST/确认集调参。校准代码应先记录 train/dev/既有 TEST 的 parent 身份交集为零、输入波形和输出维度、非有限值比例、异常全零输出比例、掩模保留率及失败率。所有候选参数在同一 DEV parent、同一场景、同一指标实现上评价，缓存候选逐 parent 输出，按预先固定的主指标和约束选一个参数配置；参数选择完成后写入配置及数据/源文件 SHA。后续独立确认只能使用该冻结配置。

不同算法的原生超参数空间并不相同，因而“给每个算法相同网格大小”并非公平性本身。应限定有来源或数值稳定性依据的窄候选范围，并公开完整搜索区间、选择目标、约束和落选结果。模型、Max-TF、GMM-OMP只接收可部署观测与已知波形常数；BCS另设 oracle 标签。不得将目标时延、SNR、JSR、干扰类型或真实干扰掩模提供给前三种方法。若某方法的实现不能处理某些输入，需记为失败而不是静默删除 parent。

## 建议的 DEV 选择准则

为了避免用单一波形误差奖励“把全部输出压低”，候选配置至少同时报告 `u_nmse`、`damage`、SJRIF、Pd、无目标受扰帧虚警以及纯噪声保持诊断。先以预定的波形误差和目标损伤可接受范围筛选可行配置，再比较 SJRIF、检测和虚警的 Pareto 关系；若无候选支配，则保留明确的折中点并在确认前冻结。具体容差需由既有 DEV 分布制定并随配置留痕，不能查看确认结果后修改。

BCS 的稀疏系数已完成 DEV-only GCV 选择记录及固定 λ 敏感性对照。其输入仍为真实支撑，所以该校准不改变 oracle 身份。Max-TF 与 GMM-OMP 已按冻结候选集合完成 64-parent DEV pilot，但未有配置通过约束；它们没有进入 256-parent DEV 复核，也没有独立确认结果。不得把 pilot 失败写成算法类别无效。

## 2026-11-16 校准结果与相位原点复核

Max-TF 的 9 项和 GMM-OMP 的 8 项预设 DEV pilot 均已完成，但没有候选通过既定门槛，因此没有进入 256-parent DEV 复核或独立确认。BCS 的 DEV-only GCV 选中 `λ=0.001`；另有同 cohort 的 `λ=0.01` 敏感性收据。BCS 继续标记为 oracle 参考。具体数字和收据索引见 `CLASSICAL_BASELINE_AND_ABLATION_STATUS_20261116.md`。

本轮另核验了生成器居中快时间与冻结 GMM-OMP 零原点本振的差异。项目参数下两者去斜结果相差固定相位及 450 点的整数 DFT 频移；合成回归测试支持 OMP 的频移等变性，故该差异不足以解释高损伤或高虚警。没有修改冻结源文件，也没有据此创建新校准版本。诊断细节见 `GMM_OMP_PHASE_ORIGIN_DIAGNOSTIC_20261116.md`。

## 结论与剩余工作

已完成的是本轮预设 Max-TF/GMM-OMP DEV pilot、BCS 的 GCV 与 λ 敏感性记录、U-Net/结构与损失消融队列，以及相位原点解析/合成诊断。经典 Max-TF/GMM-OMP 没有配置通过本轮门槛，因此完整 DEV 复核和独立确认仍未执行，也没有参数冻结。服务器 B 的该消融队列已完成；新实验仍须在服务器第二篇专用目录执行。下一步若继续经典基线，应先完成来源论文逐式和数据角色审计，再写明新版本、候选范围、门槛和停止规则；不得用确认集修补 DEV 失败。论文统计呈现仍须以 parent 为比较单位，并将 seed 间波动单独报告。
