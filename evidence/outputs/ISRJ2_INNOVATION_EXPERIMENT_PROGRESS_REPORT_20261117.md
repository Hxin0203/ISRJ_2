# ISRJ_2 创新方向实验进展报告

**报告日期：** 2026-11-17  
**范围：** 从审阅 `gptpro创新性研究.md` 与 `ISRJ_2模型思路.md` 后，到当前 tail-loss 筛查训练的服务器快照。  
**数据边界：** 本报告区分新完成的 DEV 诊断、既有 TEST 汇总的回顾性重读、正在运行的训练，以及尚未实施的验证。DEV 已用于模型开发；TEST 也已被既往分析使用。两者都不能作为新模型的独立确认集。

## 当前结论

两份思路文件审阅后，工作从“列出可能的新结构”收敛为先诊断虚警失败机制，再用 U-Net 单因素筛查一个与匹配滤波检测链对齐的尾部损失。现阶段唯一新增且有定量性能结果的实验，是对六个冻结模型在共同 DEV parent 上做残差与检测失效诊断。该诊断发现匹配滤波后的残差峰与受扰帧虚警的排序关联，明显强于总背景残差能量，因而支持测试匹配滤波尾部损失这一假设。

尾部损失训练正在服务器 B 上进行。2026-11-17 12:04:27 UTC 的服务器状态显示 seed 17 已完整提交至第 97 轮，第 98 轮进行到第 24/48 个训练 step；seed 29、41 尚未开始。配对 DEV 评估尚未运行，因此**目前没有证据证明该损失改善了虚警、检测概率或目标保持，也没有筛查通过/失败结论**。

## 从思路文件到实验决策

两份文件提出或涉及相位/时移等变、教师蒸馏、多脉冲联合、匹配滤波/距离-多普勒尾部损失、长程或频率处理、归一化等候选方向。随后形成的创新方向复核把候选与已有模型和生成器机制对照：目前先验证损失与检测目标不匹配的问题；长程/频率处理及噪声基准归一化保留为后续独立因素；多脉冲结构暂缓，因为当前仿真器各受扰脉冲独立采样干扰参数，可能令跨脉冲模块利用仿真结构而非真实脉间相参性。相位等变与蒸馏尚无足够证据作为主线。

这一步包含对已经保存的 TEST 汇总数据进行回顾性重读和文献/机制审阅，**没有新训练、没有生成新的 TEST 样本，也没有把这些回顾性分析当作独立确认结果**。该分析提示 CorrectionNet 在低、中、高 JNR 区间存在不同虚警模式，并提出“相参处理增益与检测器不匹配”的假设；因 TEST 已参与既往分析，这些发现只用于提出问题和安排实验。

## 已完成的新增实验：残差与检测失效诊断

### 设计与审计范围

运行标识为 `residual_failure_diagnostic_20261117_v2`。在同一批 256 个 DEV parent 上评估 Full、参数匹配 U-Net、No-dechirp、No-RMS、No-PC、No-damage 六个模型，每个模型使用训练 seed 17、29、41 的冻结第 256 轮权重。每个物理 parent 内对三个干扰族求平均，以 parent 作为重采样单位。该分析仅读取权重与已有 DEV 数据，没有训练、改权重或导出波形。

### 三 seed 的 DEV 描述性均值

| 模型 | 目标 Pd | 受扰帧 Pfa | SJRIF (dB) | 背景残差/干扰 (dB) | 匹配滤波残差峰/噪声残差中位数 (dB) | RD 最大值/CA-CFAR 阈值 (dB) |
|---|---:|---:|---:|---:|---:|---:|
| Full | 0.860 | 0.153 | 10.30 | -15.52 | 40.72 | 0.42 |
| U-Net | 0.868 | 0.111 | 10.61 | -15.95 | 43.17 | -0.48 |
| No-dechirp | 0.873 | 0.109 | 10.70 | -16.10 | 38.95 | -0.43 |
| No-RMS | 0.872 | 0.146 | 10.34 | -15.99 | 48.05 | 1.28 |
| No-PC | 0.865 | 0.165 | 10.22 | -15.36 | 40.89 | 0.50 |
| No-damage | 0.836 | 0.091 | 10.86 | -15.91 | 34.77 | -0.14 |

以上是当前 DEV 的描述性汇总，不是独立测试集成绩或置信的总体性能排序。尤其 No-damage 的受扰帧 Pfa 最低，但 Pd 也最低（0.836），目标损伤为 0.130，高于 U-Net 的 0.048；这显示单独压低虚警可能以损伤目标为代价，不能只按 Pfa 选模型。

### 失效指标关联

在 Full 模型的三个 seed 中，parent 级匹配滤波残差峰与受扰帧虚警的 Spearman 相关为 0.656–0.677；总背景残差能量的相关只有 0.015–0.071。U-Net 对应分别为 0.546–0.582 和 0.101–0.117。最大 RD 功率相对 CA-CFAR 阈值也与帧虚警相关（Full 为 0.337–0.396，U-Net 为 0.452–0.475）。

这说明在当前 DEV 诊断中，能被匹配滤波和多脉冲积累显出的局部残留，比整体残差能量更能排列虚警风险。它是关联证据，不证明因果，也不证明优化代理指标会降低校准后的实际 Pfa。匹配滤波峰值使用噪声状态输出残差中位数作归一化；分母可能很小，所以这个量仅作排序诊断。RD/CFAR 阈值比也不是独立的经验虚警概率。

### 实验决策

据此启动 U-Net 上的单因素损失筛查：只在既有端点、脉压和目标损伤目标上增加一个目标缺席受扰状态的匹配滤波 RD 尾部代理项，测试它能否改善虚警与目标保持的折中。先在同等参数量的 U-Net 上做，避免同时改骨干而无法归因。

## 正在进行：U-Net 匹配滤波尾部损失筛查

### 冻结设计

- 对照为已经完成的参数匹配 U-Net；三 seed 为 17、29、41。
- 每 seed 训练 256 轮、12,288 updates；数据、父样本/干扰采样、初始化流程、优化器、学习率计划、FP32 精度保持与冻结 U-Net 对照一致，活动参数量为 59,714。
- 唯一改变是在既有 `endpoint + 0.1 × pulse-compression + target-damage` 目标上加 `0.05 × L_tail`。
- 尾部代理从目标缺席状态的残差出发，采用 600 点 LFM 匹配滤波、8 脉冲慢时间 FFT、目标自由噪声 RD 功率归一化，并在有效距离单元及预定 CA-CFAR 参考窗阈值附近惩罚平滑 top-8 尾部。该项是可微筛查代理，不是经验 CFAR 检测器，也不保证目标虚警率。
- 每轮保留不可变恢复点，每 32 轮保留里程碑。训练与权重均保存在服务器 B（`rsdr-b`）的 `D:/code/Xin/ISRJ_222`，物理 GPU 1；没有在本机训练。

### 预设筛查门槛和解释

只有当三 seed 的受扰帧 Pfa 差值中位数小于 0、每个 seed 的 Pd 绝对变化不低于 −0.02、平均目标损伤变化不高于 +0.005，才进入下一轮探索。该门槛是资源分配规则，不是显著性检验；不根据 DEV 选择 epoch 或 seed。通过也只意味着值得继续研究，不构成确认结论。失败则停止这条尾部损失分支并记录负结果。

到目前为止没有把训练损失曲线当成检测结果；现有轻量状态记录的训练损失只反映优化过程，不能替代 Pd、Pfa 或目标损伤。当前 paired DEV 结果文件尚未产生。

## 尚未开始的工作

1. **完成三 seed tail-loss 训练与 paired DEV 筛查。** 先审计所有每轮恢复点与里程碑，再对相同 DEV parents 做成对比较，报告 U-NMSE、目标损伤、SJRIF、Pd、受扰帧/单元 Pfa 和残差尾部指标，并按干扰强度分层。
2. **长程/频率处理与归一化的独立筛选。** 只有尾部损失筛查通过后才启动；长程/频率算子和噪声基准归一化分开改变，每次保留同种子、同数据、同更新数的控制。不要在同一次筛查里组合因素。
3. **组合有效因素。** 只组合单因素筛查支持的因素，冻结方法、训练预算与评价口径。不得用 DEV 挑选最终 seed 或 epoch。
4. **新确认 parent 集。** 组合方案固定后再生成与训练/DEV 不重叠的新确认集，另行冻结校准与检测阈值。在此之前，不能把当前 DEV 或既有 TEST 重新命名为确认集。
5. **暂缓方向。** 相位/时移等变、教师蒸馏、多脉冲联合均未做实验。多脉冲方向需先让生成器具有可控、符合物理的跨脉冲相参模式，再评估是否引入结构。

## 限制与风险

- 当前新完成的诊断只有 DEV 一个数据角色和三个训练 seed；parent bootstrap 只刻画固定模型下的 parent 抽样变化，不能替代训练 seed 不确定性。
- DEV 与 TEST 均参与过开发或既往分析。现有数字只能支持机制诊断和筛查设计，不能视作无偏的新方法确认。
- 相关性不能证明匹配滤波峰是虚警的原因；尾部损失代理也未必等价于校准 CFAR 下的经验虚警。
- 当前模型间 Pd/Pfa 均值用于交代诊断现象，不作为最终模型排名，也没有进行多重比较后的统计推断。
- 两份思路文件中提出的其他方向还没有训练或独立评估结果。
