# ReCoVP-Hybrid 与 RSDR-Net：SNR/JSR 分层图

本目录包含 Hybrid seed 17（epoch 256 DEV）与第一篇 RSDR-Net（seed 40312102、epoch 32 主扫描）的五项分层性能图：`u_nmse`（对应第一篇的 $e_U$）、`damage`（对应 $e_S$）、检测率 $P_d$、干扰帧虚警率及 SJRI-F。每张图以 SNR 为横轴、指标为纵轴，颜色代表 10 dB JSR 桶；实线圆点为 Hybrid，虚线方点为 RSDR-Net。PNG 便于查看，PDF 可用于排版，汇总点估计与样本数见 `SNR_JSR_metric_summary.csv`。

两边使用共同的 SNR 桶 `[-20,-15)、[-15,-10)、[-10,-5)、[-5,0)、[0,5)` dB 和 JSR 桶 `[-10,0)、[0,10)、[10,20)、[20,30)、[30,40)` dB。横坐标标出每个 SNR 桶的中点。缺失分层显示为空，不插值。Hybrid 曲线按物理 parent 平均，半透明带为 parent bootstrap 95% 区间；图中 `n=` 是相应格内的 Hybrid parent 数。RSDR-Net 曲线是主扫描落入该 SNR×JSR 桶的精确条件点估计等权均值；此 SNR×JSR 分层通常含 12 个条件点（3 类干扰 × 4 个 5 dB SNR 点），没有从逐条件区间拼造总区间。

**比较限制：**两套结果不是相同 parent 上的配对测量，输入场景覆盖、条件权重和聚合方式也不完全相同，因此图用于描述趋势，不能据此宣称显著性或全条件优越。Hybrid 的部分分层格样本很少（图中 `n` 可见，若干格仅 1–3 个 parent），边缘 JSR 桶尤其不稳定；宽置信带也提示估计不确定。解释检测率时须同时看干扰帧虚警率；`u_nmse`、`damage/e_S` 越低越好，检测率和 SJRI-F 越高越好，虚警率越低越好。

总体 DEV 汇总（未按 JSR 分层）显示 Hybrid 的 `u_nmse=0.0431`、`damage/e_S=0.0597`、$P_d=87.1\%$、干扰帧虚警率 `5.6%`、SJRI-F `11.10 dB`；RSDR 主扫描 168 条件格等权均值分别为 `0.1023`、`0.0718`、`68.0%`、`7.1%`、`4.74 dB`。这些总体点值同样受非配对和覆盖差异限制，应以同条件、同 parent 的完整复评作为最终横向结论依据。

复现脚本：仓库 `tools/plot_hybrid_rsdr_snr_jsr.py`。绘图只读取已有评测产物，不启动训练或模型推理。
