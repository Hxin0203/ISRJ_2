# ISRJ_2: target-response-constrained restoration

This repository contains the controlled source and evidence snapshot for the second ISRJ paper. Start with [PAPER2_PROGRESS_CHECK_20261115.md](PAPER2_PROGRESS_CHECK_20261115.md) for the completed training and original TEST audit, and [PAPER2_RSDR_UNIFIED_COMPARISON_20261115.md](PAPER2_RSDR_UNIFIED_COMPARISON_20261115.md) for the additive comparison with the first-paper RSDR-Net. [ISRJ_2_CURRENT_STATE_REPORT_20261113.md](ISRJ_2_CURRENT_STATE_REPORT_20261113.md) preserves the earlier project history, model structure and mathematical formulation. Results concern the stated simulation distributions; novelty and field performance remain unestablished.

The 1103-aligned execution is documented in [PAPER2_1103_PROGRESS_20261114.md](PAPER2_1103_PROGRESS_20261114.md) and [PAPER2_1103_NEAR_TERM_PLAN_20261114.md](PAPER2_1103_NEAR_TERM_PLAN_20261114.md). The independent original TEST completed with the frozen seed-29/epoch-128 checkpoint: 2,237 method-condition receipts and 103,826 audited parent blocks. The additive RSDR-Net comparison has its own 564-condition freeze and completion receipts under `evidence/outputs/RSDR_UNIFIED_20261115/`; read its current report for audited coverage. Both models use the same second-paper TEST parents, pulse compression, Doppler processing and CFAR. This is one frozen seed per model with different training budgets; Pd must be interpreted alongside empirical false alarms. MCA-ADMM-Net, FNet and ablations remain paused.

The follow-up specified in [PAPER2_256_EPOCH_8_SEED_PLAN_20261114.md](PAPER2_256_EPOCH_8_SEED_PLAN_20261114.md) has completed: seeds 17, 29, 41, 53, 67, 79, 97 and 109 all reached epoch 256, with 64 immutable 32-epoch milestones, 64 DEV evaluations and 2,048 epoch metric rows. Earlier checkpoints and recovery archives are retained. Convergence data and figures are under `evidence/outputs/CONVERGENCE_256_8SEED_20261114/` and `evidence/outputs/PROGRESS_CHECK_20261115/`. These expanded-model results are DEV evidence; they do not replace the frozen epoch-128 TEST or justify TEST-based model reselection.

`PAPER2_EXPERIMENT_ROADMAP_20261114.md` records the earlier broader roadmap. The active scope is the 1103-aligned protocol above: MCA-ADMM-Net, FNet, and ablations are paused.

Read PAPER2_GO_NO_GO.md and PAPER2_PILOT_RESULTS.md for the initial pilot, and PAPER2_DEV_CONFIRMATION.md for its subsequent failed frozen confirmation. FAMILY_STUDY_CONTRACT.md and FAMILY_STUDY_FREEZE.json define the separate target-family experiment; its completed development results are in PAPER2_FAMILY_RESULTS.md and evidence/family/RESULTS.json. PAPER2_NEAREST_WORK_COMPARISON.md records literature access limits.

Run from this directory with an existing Python environment containing NumPy, PyTorch, pytest and matplotlib:

```powershell
python -m pytest tests -q
python -m paper2.run engineering
python -m paper2.run train
python -m tools.run_evaluation
```

The first pilot and its confirmation are complete and immutable. Do not rerun its evaluator to replace the updated go/no-go decision. The bounded prospective follow-up is run separately:

```powershell
python -m tools.family_study train
python -m tools.family_guard
```

The family guard performs pre-DEV identity checks, freezes DEV-selected gains before generating new confirmation parents, and verifies the resulting provenance. Completed family results are preserved rather than automatically reselected. No formal TEST is generated by these commands.

Observed-only waveform restoration is available through `python -m tools.restore_waveform --help`. It accepts complex observations and a fixed checkpoint/global gain; it never accepts true target/jammer components. Do not describe these development weights as a validated production or field model.

The engineering command freezes training length from measured cost. Completed runs are preserved and source/config/checkpoint hashes must match. A partial scientific run deliberately requires investigation before restart. The evaluation wrapper checks supplemental dataset bindings, all six run identities, identical per-seed initialization and minibatches, then performs DEV-only analysis. Do not bypass it by calling paper2.evaluate directly.

Local data, weights and raw outputs stay in ignored data/ and outputs/. Only screened source, contracts and small derived evidence belong in Git. No old held-out Gate arrays are read. The original pipeline is complete; current additive-comparison progress is tracked in `handoff/RUNNING_EXPERIMENTS.json` and `evidence/outputs/RSDR_UNIFIED_20261115/RUN_STATUS.json`. Known waveforms and all old source snapshots have origin hashes in SOURCE_MANIFEST.json. Push this work only to the dedicated `paper2` remote (`Hxin0203/ISRJ_2`).
