## 二、这次五个 seed 的结果说明

纳入 seed **17、29、41、53、67**，全部使用 **epoch 256**；每个 seed 为 12,288 次更新，共计 61,440 次。已补齐五种子和冻结 RSDR 的同场景 DEV 推理、脉压/相位/多普勒分析，并汇总 Equal-PFA、32 格 SNR×JSR、12 类卷积对照和五种子冻结推理干预；本次没有新增训练，没有打开独立确认集。

| 指标或范围 | Hybrid 五种子平均 | 第一篇 RSDR-Net |
| --- | --- | --- |
| 检测率：1% 校准虚警目标 | 56.38% | 73.50% |
| 检测率：5% 校准虚警目标 | 88.31% | 88.72% |
| 检测率：10% 校准虚警目标 | 91.06% | 91.06% |
| SNR×JSR 网格平均 E_U，越低越好 | 0.07284 | 0.11478 |
| SNR×JSR 网格平均 E_S，越低越好 | 0.04269 | 0.09105 |
| DEV 脉压目标相干功率损失，越低越好 | 0.778 dB | 1.101 dB |

结论：Hybrid 在 5%/10% 校准虚警点稳定优于两种卷积 Tail 基线；相对于第一篇 RSDR，目标保真有所改善，但不能宣称所有指标全面超过。网格平均 E_U、E_S 分别降低约 36.53%、53.11%；固定 DEV 的 E_U 却高于 RSDR，说明排名依赖评测分布。DEV 脉压少损失约 0.323 dB；目标增量的相位和多普勒误差更小，但实际含噪输出的多普勒估计尚未证实改善。

seed 67 的纯噪声改动 E0 明显高于其余四个 seed，已保留并单独分析。以上虚警百分数是校准目标，不保证各方法的实际评测虚警完全相同；实测值和置信区间见完整报告。RSDR 只有一个冻结 seed，卷积基线通常三个 seed，不能视作五对五训练复现实验。
